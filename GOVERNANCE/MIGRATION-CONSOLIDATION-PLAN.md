# QURBATA Migration & Consolidation Plan

## Tujuan
Menjadikan GitHub sebagai single source of truth seluruh proyek QURBATA.

## Aturan Utama
- Tidak membuat dokumen baru sebelum audit dokumen lama.
- Dokumen final menjadi sumber utama.
- Draft lama dipindahkan ke archive atau dihapus setelah migrasi dan verifikasi.
- Semua proyek turunan wajib merujuk repository utama.

## Tahapan
1. Audit seluruh file dan sumber lama.
2. Klasifikasi: FINAL / DRAFT / ARCHIVE / DUPLIKAT.
3. Migrasi dokumen final ke struktur resmi.
4. Verifikasi isi.
5. Hapus duplikasi yang sudah tidak digunakan.

## Struktur Target

- GOVERNANCE
- CURRICULUM
- BOOKS
- ASSESSMENT
- ASSET
- ARCHIVE

## Status
Migration in progress.
