# DEC-GOV-004 — Keputusan Ratifikasi Governance QURBATA v1.0

**Tanggal Efektif:** 27 Juli 2026

**Freeze-ID:** GF-2026-001  
**Baseline:** `20892fbd5892dc2a79f23012ed6c98d0685a6eaa`

## 1. Pernyataan Ratifikasi

> Saya, Aris Liswanto, meratifikasi Governance QURBATA v1.0 berdasarkan DEC-GOV-004, efektif 27 Juli 2026.

Pernyataan tersebut diberikan secara eksplisit oleh pengesah pada 27 Juli 2026 dan menjadi dasar perubahan GF-16 menjadi PASS serta GF-2026-001 menjadi FROZEN.

## 2. Keputusan

Governance QURBATA v1.0 Bahasa Indonesia diratifikasi dan ditetapkan efektif sejak 27 Juli 2026 berdasarkan baseline yang disebutkan di atas.

## 3. Ruang Lingkup

Keputusan mencakup paket Governance v1.0 Bahasa Indonesia sebagaimana dirinci dalam BAS-GOV-001: QC-000–QC-012, README tata kelola, toolkit, register, matriks, checklist, audit, bukti, dan riwayat branch sampai baseline kandidat.

## 4. Pengecualian

Keputusan tidak meratifikasi:

1. terjemahan Inggris atau Arab;
2. implementasi produksi RIQA OS;
3. bukti operasional lapangan di luar bukti minimum governance;
4. produk kurikulum atau buku QURBATA; dan
5. commit setelah baseline, kecuali dinilai dan dimasukkan melalui perubahan sah.

## 5. Transisi

1. GF-16 dinilai PASS dan GF-2026-001 berstatus FROZEN.
2. Paket yang tercakup menjadi baseline Governance v1.0 efektif.
3. PR #1 dapat keluar dari Draft dan masuk Ready for Review.
4. Tindak lanjut non-blocking dipantau pada gate implementasi, kurikulum, buku, terjemahan, dan RIQA OS masing-masing.
5. Perubahan material setelah freeze wajib mempunyai Decision-ID, versi baru, alasan, dampak, dan bukti persetujuan.

## 6. Tinjauan Berikutnya

Tinjauan paling lambat 27 Juli 2029, atau lebih awal jika terjadi perubahan material, insiden kritis, perubahan hukum/syariah yang relevan, perubahan struktur kewenangan, atau pembukaan kembali baseline.

## 7. Konflik Kepentingan dan Independensi

Perangkapan peran tahap pendirian dicatat dan dikendalikan melalui pemisahan penyusunan, telaah, verifikasi bukti, dan pengganti. Penelaahan independen serta register keberatan merupakan bagian dari bukti keputusan.
