# REC-GOV-012 — Penetapan Format Nomor Perkara Safeguarding

**Kode Rekaman:** REC-GOV-012  
**Judul:** Penetapan Format Nomor Perkara Safeguarding QURBATA  
**Tanggal Penetapan:** 27 Juli 2026  
**Pemberi Persetujuan:** Aris Liswanto  
**Status:** Berlaku untuk Operasional Awal  
**Klasifikasi Akses:** Internal; format ID dapat dipublikasikan  
**Dokumen Terkait:** QC-002, QC-009, QC-012, REC-GOV-006, REG-GOV-013

## 1. Format

1. perkara nyata: `SAFE-TAHUN-NOMOR`, contoh `SAFE-2026-0001`;
2. simulasi: `SAFE-TAHUN-TEST-NOMOR`, contoh `SAFE-2026-TEST-001`; dan
3. nomor berjalan dimulai kembali pada setiap tahun kalender.

## 2. Aturan Kerahasiaan

Nama, inisial, kelas, alamat, nomor kontak, atau identitas santri tidak boleh dimasukkan dalam nomor perkara maupun subjek email. Hubungan antara Case-ID dan identitas hanya disimpan dalam register terbatas yang dapat diakses berdasarkan kebutuhan tugas.

## 3. Persetujuan

Aris Liswanto menyatakan:

> Setuju format nomor perkara.

## 4. Kendali

Setiap laporan yang diterima diberi Case-ID sesegera mungkin. Duplikasi, pembatalan, penggabungan, atau koreksi nomor tidak boleh menghapus audit trail.
