# REC-GOV-014 — Penunjukan Awal Pengganti Document Controller

**Kode Rekaman:** REC-GOV-014  
**Judul:** Penunjukan Awal Izathy Khoirina sebagai Pengganti Document Controller QURBATA  
**Tanggal Penunjukan:** 27 Juli 2026  
**Pemberi Penunjukan:** Aris Liswanto  
**Personel:** Izathy Khoirina  
**Status:** Mandat Diterima; Siap Diaktifkan saat Diperlukan  
**Klasifikasi Akses:** Internal  
**Dokumen Terkait:** QC-002, QC-003, QC-004, MAT-GOV-001

## 1. Penunjukan

Izathy Khoirina ditunjuk sebagai pengganti Document Controller apabila Aris Liswanto berhalangan.

## 2. Penerimaan Mandat dan Deklarasi Konflik

Izathy Khoirina menyatakan:

> Saya bersedia menjadi pengganti Document Controller QURBATA apabila Aris Liswanto berhalangan. Saya bersedia menjaga kerahasiaan, ketertiban versi, metadata, arsip, dan audit trail dokumen. Saya tidak memiliki konflik kepentingan; jika konflik muncul, saya akan segera mengungkapkannya dan tidak menangani keputusan tersebut.

## 3. Batas Kewenangan

Kewenangan hanya aktif apabila delegasi dicatat. Pengganti dapat menjalankan pengendalian nomor dokumen, metadata, versi, publikasi, dan arsip sesuai prosedur, tetapi tidak boleh mengubah makna normatif atau menyetujui perubahan material di luar kewenangannya.

## 4. Syarat Aktivasi

1. penerimaan mandat, komitmen kerahasiaan, dan deklarasi konflik telah dipenuhi;
2. memahami pengendalian versi, metadata, audit trail, dan klasifikasi akses;
3. mengungkap setiap konflik yang muncul;
5. tidak menghapus atau menimpa rekaman versi secara tidak terlacak; dan
6. mencatat waktu mulai serta berakhirnya delegasi.
