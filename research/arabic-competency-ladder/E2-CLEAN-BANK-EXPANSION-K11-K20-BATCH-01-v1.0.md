## K11 — detached pronoun as mubtada'
Canonical: `هُوَ الْعَلِيُّ` — 2:255.
Additional clean occurrence in the same verified verse family: `هُوَ الْحَيُّ الْقَيُّومُ` is not present as such in 2:255; therefore it is not credited. The verse begins `اللَّهُ ... هُوَ الْحَيُّ الْقَيُّومُ`, where `هو` is embedded after an exception construction and is not used as a second minimal K11 item.

**Verdict:** E1; independent clean anchor still required.

## K12 — jar–majrur as khabar
Canonical: `لِلَّهِ الْحَمْدُ` — 45:36.
Candidate: `لَهُ مَا فِي السَّمَاوَاتِ` — 2:255. This does show fronted `له`, but the nominal subject is relative/general `ما...`, which raises structural complexity beyond the minimal K12 core item.

**Verdict:** E1; candidate retained as transfer, not clean-bank promotion evidence.

## K13 — two-noun idhafah
Canonical: `رَسُولُ اللَّهِ` — 48:29.
Verified additional idhafah spans:
- `أَثَرِ السُّجُودِ` — 48:29
- `عِلْمِهِ` — 2:255, but this uses an attached pronoun and therefore belongs functionally closer to K18 than a clean two-overt-noun K13 item.

`أَثَرِ السُّجُودِ` provides a second overt-noun lexical pair, but both current clean examples are in one verse (48:29). A third independent verse is preferred before E2.

**Verdict:** E2 CANDIDATE, not yet promoted.

## K14 — overt nominal direct object
Canonical: `وَرِثَ سُلَيْمَانُ دَاوُدَ` — 27:16.
Verified later-passage seed: `وَعَدَ اللَّهُ الَّذِينَ آمَنُوا` — 48:29 contains an overt object headed by relative `الذين`; this imports K23 and is therefore not a clean K14 core item.

**Verdict:** E1; seek ordinary overt nominal object without relative-clause dependency.

## K15 — attached-pronoun segmentation
Canonical: `رَبِّكَ` — 96:1.
Verified diversified host forms:
- `عِندَهُ` — 2:255
- `كُرْسِيُّهُ` — 2:255
- `مَثَلُهُمْ` — 48:29

Operation is segmentation only: host + attached pronoun. These provide noun/adverbial-host variation and singular/plural suffix variation. Functional role is explicitly not tested.

**Verdict:** PROMOTE E1 → E2.

## K16 — conjunction recognition
Canonical: `دَاوُدَ وَسُلَيْمَانَ` — 27:15 (`و`).
Verified additional marker occurrences:
- `سِنَةٌ وَلَا نَوْمٌ` — 2:255 (`و`)
- `السَّمَاوَاتِ وَالْأَرْضَ` — 2:255 (`و`)
- `مَغْفِرَةً وَأَجْرًا` — 48:29 (`و`)

These diversify coordinated nominal environments but still only exercise `و`. Since K16's frozen family also includes validated `ف` and `ثم`, E2 promotion is withheld until marker-family diversity is represented.

**Verdict:** E1+ / E2 CANDIDATE.

## K17 — simple na'at–man'ut
Canonical: `الصِّرَاطَ الْمُسْتَقِيمَ` — 1:6.
Verified seed: `أَجْرًا عَظِيمًا` — 48:29 is a clear noun + adjective pair with visible agreement and different case/definiteness profile from the canonical anchor.

Two strong independent anchors now exist. One additional clean pair is preferred for E2 promotion.

**Verdict:** E2 CANDIDATE.

## K18 — attached pronoun as mudaf ilayh
Canonical: `عَبْدِهِ` — 17:1.
Verified diversified noun-host possessive/genitive forms:
- `عِلْمِهِ` — 2:255
- `كُرْسِيُّهُ` — 2:255
- `مَثَلُهُمْ` — 48:29

All require assigning the attached pronoun as the noun's genitive/possessive complement, not merely segmenting it.

**Verdict:** PROMOTE E1 → E2.

## K19 — coordination of two nominal units
Canonical: `دَاوُدَ وَسُلَيْمَانَ` — 27:15.
Verified independent nominal coordination:
- `السَّمَاوَاتِ وَالْأَرْضَ` — 2:255
- `مَغْفِرَةً وَأَجْرًا عَظِيمًا` — 48:29; target relation can be limited to heads `مغفرةً` + `أجرًا`, while adjective modification remains outside the target.

This provides multiple independent verses and different nominal roles while preserving the coordination operation.

**Verdict:** PROMOTE E1 → E2.

## K20 — preposition + attached pronoun
Canonical: `لَهُ` — 2:255.
48:29 provides `مِنْهُمْ`, a direct preposition `من` + attached pronoun `هم`, with no intervening noun host. This diversifies both preposition and pronoun number.

Need a third clean direct preposition+pronoun occurrence before formal E2 promotion under the conservative bank rule.

**Verdict:** E2 CANDIDATE.

## Boundary controls

1. `بِإِذْنِهِ` remains excluded from K20 because the suffix attaches to noun `إذن`, not directly to the preposition.
2. `وَعَدَ اللَّهُ الَّذِينَ آمَنُوا` is not credited to K14 core because object recognition would import relative-pronoun competence K23.
3. `لَهُ مَا فِي السَّمَاوَاتِ` is retained as transfer for K12 because its subject is structurally more complex than the minimal core pattern.
4. K15 segmentation evidence must not be counted as K18/K20 mastery unless the learner assigns the suffix's function.
5. K16 marker recognition remains distinct from K19 nominal coordination and K58 clause coordination.
