## K11 — detached pronoun as mubtada'

Canonical:
- `هُوَ الْعَلِيُّ` — 2:255

Independent clean expansion:
- `هُوَ اللَّهُ` — 59:22 (minimal target for detached-pronoun predication; following relative material excluded)
- `هُوَ اللَّهُ` — 59:23 (independent verse occurrence; longer divine-name sequence excluded from target)

Boundary:
- recognition of `هو` alone is K05; K11 requires learner to identify it as the overt mubtada' in predication.
- PP/clausal khabar remains outside K11 core.

**Verdict: K11 → E2.**

## K12 — jar–majrur as khabar

Canonical:
- `لِلَّهِ الْحَمْدُ` — 45:36

Expansion candidates:
- `لَهُ الْحَمْدُ` — 28:70
- `لَهُ الْمُلْكُ وَلَهُ الْحَمْدُ` — 64:1 (contains two PP-fronted predications; second unit can be isolated for target use)

Boundary:
- `لَهُ مَا فِي السَّمَاوَاتِ` (2:255) is not preferred as core K12 because the postposed subject is a relative/generalized `ما` construction rather than a simple overt nominal unit.

**Verdict: K12 → E2** subject to retaining minimal target spans in teaching items.

## K13 — two overt nouns in idhafah

Canonical:
- `رَسُولُ اللَّهِ` — 48:29

Clean expansion:
- `رَبِّ الْعَالَمِينَ` — 1:2
- `مَالِكِ يَوْمِ` — 1:4 as the local two-noun edge `مالكِ يومِ`; the continuation `الدين` forms a longer chain and is excluded from the minimal K13 target.

Boundary:
- K13 teaches the local two-noun idhafah relation; three-member chain mastery is transfer/advanced relative to this core target.

**Verdict: K13 → E2.**

## K14 — overt nominal direct object

Canonical:
- `وَرِثَ سُلَيْمَانُ دَاوُدَ` — 27:16

Clean expansion:
- `خَلَقَ الْإِنسَانَ` — 96:2 (overt direct object `الإنسان`; subject is morphologically encoded in the verb, so this is suitable only after K41 if used as full syntactic analysis, but object recognition itself remains visible)
- `عَلَّمَ الْقُرْآنَ` — 55:2 (overt object `القرآن`; same hidden-subject caution)

Because two expansions introduce a hidden subject if the whole clause must be analyzed, they are useful object-recognition evidence but not fully cumulative-clean replacements for the canonical overt-subject anchor.

**Verdict: K14 remains E1 / E2 candidate.** Need another overt-subject + overt-object independent occurrence before formal E2.

## K16 — validated conjunction recognition

Canonical:
- `دَاوُدَ وَسُلَيْمَانَ` — 27:15 (`و`)

Expansion:
- `سِنَةٌ وَلَا نَوْمٌ` — 2:255 (`و` in coordinated negative nominal material)
- `السَّمَاوَاتِ وَالْأَرْضَ` — 2:255 (`و`)
- `رَبِّ السَّمَاوَاتِ وَرَبِّ الْأَرْضِ` — 45:36 (`و`)

The current clean bank strongly validates `و`. It does not yet demonstrate the full frozen marker family `و / ف / ثم` at diversified occurrence level.

**Verdict: K16 remains E2 candidate**, pending clean `ف` and `ثم` recognition examples with function validation.

- `أَجْرًا عَظِيمًا` — 48:29

These show definite and indefinite adjective agreement with distinct lexical material.

Boundary:

**Verdict: K17 → E2.**

## K20 — preposition + attached pronoun

Canonical:
- `لَهُ` — 2:255

Expansion:
- `عِنْدَهُ` is NOT counted because `عند` is a noun/adverbial host, not a direct preposition.
- `مِنْهُمْ` — 48:29 is clean direct preposition + attached pronoun.
- `عَلَيْهِمْ` — 1:7 is clean preposition + attached pronoun.

Boundary:
- `بِإِذْنِهِ` is excluded because the suffix attaches to `إذن`, not directly to `بـ`.

**Verdict: K20 → E2.**
