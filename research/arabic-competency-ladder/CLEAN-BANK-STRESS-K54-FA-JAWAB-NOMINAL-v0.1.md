# Clean Bank + Stress Test K54 — Predictive `فاء جواب الشرط` with Nominal Response v0.1

**Status:** PRE-FREEZE STRESS TEST  
**Baseline:** K1–K53 DRAFT-FROZEN.

## Operation under test

Given a validated simple conditional construction whose intended response is a recognizable **jumlah ismiyah**, learner predicts that the response is linked with `فاء جواب الشرط`, then verifies the overt fā’ in the occurrence.

Core reasoning:

`جواب ذو بنية اسمية → توقّع الفاء → تحقق من فاء جواب الشرط`

The new operation is predictive rule use, not post-hoc marker recognition.

## Clean-bank admission rules

PASS only when:
- condition boundary is already analyzable through K47;
- response is clearly a nominal clause using earlier competencies;
- `فـ` is overt and securely classified as `فاء جواب الشرط` through K48;
- prediction can be made from response type without an additional unmastered rule;
- no oath/condition competition;
- no omitted jawab;
- no disputed clause classification.

## Evidence classes

### PASS-A — transparent nominal response
Simple condition + overt fā’ + unmistakable jumlah ismiyah response.

### PASS-B — cumulative-clean nominal response
The nominal response contains additional material already analyzable ≤ K53 but remains clearly nominal at its structural core.

### REVIEW-BOUNDARY
The response may be nominal but its exact boundary is not clean enough for first-stage prediction.

### REVIEW-TYPE
Classifying the response as nominal requires later syntax.

### PREMATURE
- non-nominal response categories;
- multiple traditional reasons for obligatory fā’ operating simultaneously;
- omitted or disputed response;
- nested conditional structure.

## Anti-list stress test

K54 passes only if assessment can be solved by a generative decision:

1. identify response type as nominal;
2. predict need for fā’;
3. verify the marker.

The learner is **not** asked to recite a list of all جواب types requiring fā’.

## Distinctness from K48

K48 is receptive/post-hoc:
`see fā’ → classify it → locate response`.

K54 is predictive:
`recognize nominal response type → predict fā’ → verify`.

Therefore the task direction and learner operation differ.

## Expansion policy

Do not automatically add other response types to K54. Each new type must pass a transfer test:
- if the same predictive abstraction transfers without a new rule burden, treat as application breadth;
- if it requires a distinct structural/semantic criterion, rescan before inclusion.

## Stress-test verdict

**PASS WITH SINGLE-TYPE CORE.**

The nominal-response case provides a genuinely generative K54 without converting the competence into traditional-list memorization.

## Freeze recommendation

> **K54 — Memprediksi kebutuhan `فاء جواب الشرط` ketika jawab syarth yang tervalidasi berbentuk jumlah ismiyah, lalu memverifikasi marker tersebut pada occurrence Qurani.**
