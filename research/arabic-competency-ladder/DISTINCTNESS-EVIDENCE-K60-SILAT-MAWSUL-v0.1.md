# DISTINCTNESS + EVIDENCE GATE K60 — `صلة الموصول` v0.1

**Status:** PRE-FREEZE EVIDENCE GATE  
**Baseline:** K1–K59 DRAFT-FROZEN.

## Candidate

> **K60 — Mengenali `صلة الموصول` sebagai klausa yang melekat pada `اسم موصول` eksplisit dalam konstruksi Qurani sederhana dan tervalidasi.**

Core representation:

`[اسم موصول] + [جملة صلة الموصول]`

## New learner operation

Given a validated occurrence, learner must:
1. identify an overt familiar `اسم موصول`;
2. identify the span of the following clause;
3. attach that clause to the relative marker as its `صلة الموصول`;
4. distinguish this attachment from clause coordination, sequencing, or an independent following sentence.

The target is **attachment + boundary recognition**, not recognition of the lexical form `الذي/الذين` alone.

## Distinctness tests

### Test 1 — Against lexical inventory
If the learner merely circles `الذي` or `الذين`, K60 is not demonstrated. The learner must locate the full relative clause span.

**Result: PASS.**

### Test 2 — Against K58 coordination
K58 links two peer clauses. K60 attaches one clause to an overt nominal relative head.

`clause ↔ clause` vs `اسم موصول → clause`.

**Result: PASS.**

### Test 3 — Against K59 sequencing
K59 adds temporal ordering between peer clauses. K60 is not a temporal/discourse relation; it is a local modifier/complementing relation anchored by a relative marker.

**Result: PASS.**

### Test 4 — Against ordinary adjective/phrase modification
K60 requires a **clause** as the attached material. If only a word or phrase modifies a noun, the occurrence does not count as K60 evidence.

**Result: PASS.**

## Core scope

Initial examples should prefer:
- overt familiar forms such as `الذي`, `الذين`, or another explicitly validated relative marker;
- short verbal or nominal relative clauses;
- clause-internal material analyzable ≤ K59;
- clear start/end boundary;
- no need to teach the full relative-pronoun paradigm.

## `العائد` policy

The resumptive element (`العائد`) is **not a mandatory analysis target in core K60**. It may be present, but the item is admitted only when the learner can identify the `صلة` boundary and attachment without a new operation devoted to resumptive-pronoun theory.

If identifying the relative clause depends on reconstructing or analyzing a difficult `عائد`, classify the occurrence as REVIEW rather than core PASS.

## Evidence classes

### PASS-A — transparent overt relative marker
Familiar `اسم موصول` + short, clear following clause + unambiguous attachment.

### PASS-B — cumulative-clean relative clause
The `صلة` contains previously mastered complexity, but its clause boundary remains clear and no new relative-clause operation is added.

### REVIEW-AID
Attachment is likely, but understanding the resumptive structure requires later theory.

### REVIEW-BOUNDARY
Relative marker is clear, but the end of the `صلة` is not sufficiently transparent for first-stage teaching.

### REVIEW-MARKER
The form can function relatively, but its status in the occurrence is not locally obvious without later analysis.

### PREMATURE
- nested relative clauses;
- long-distance or omitted resumptives requiring reconstruction;
- disputed attachment;
- simultaneous ellipsis or advanced discourse dependency;
- full `الأسماء الموصولة` paradigm as prerequisite.

## Anti-inventory rule

Do not create separate K numbers for `الذي`, `التي`, `الذين`, etc. These are lexical/form variants within one structural operation when the learner action remains:

`recognize relative head → find attached clause → mark its boundary`.

## Assessment design

Core prompt:

`أين الاسم الموصول؟ وأين تبدأ صلته وأين تنتهي؟`

Expected response identifies the relative marker and the full attached clause span.

## Evidence-gate verdict

**PASS WITH SHORT-CLAUSE / OVERT-MARKER SCOPE.**

K60 is structurally distinct, cumulative, and assessable without importing full resumptive-pronoun theory.

## Freeze recommendation

> **K60 — Mengenali `صلة الموصول` sebagai klausa yang melekat pada `اسم موصول` eksplisit, serta menentukan batas awal–akhir klausa tersebut dalam konstruksi Qurani sederhana.**
