## 1. K11 — Dhamir Munfashil sebagai Mubtada' dalam Jumlah Ismiyyah Sederhana

Target relation: `ضمير منفصل + خبر`.

### Evidence awal

| Ref | Quranic unit | Target | Status | Notes |
|---|---|---|---|---|
| 2:5 | `أُولَٰئِكَ هُمُ الْمُفْلِحُونَ` | pronoun-based nominal predication | REVIEW | membawa isim isyarah; bukan core K11 bila `أولئك` belum dipelajari |
| 2:37 | `هُوَ التَّوَّابُ الرَّحِيمُ` | `هو` mubtada' + khabar nominal | REVIEW-PASS | khabar diperluas dua sifat/nominal; core relation valid tetapi expansion perlu ditandai |
| 3:2 | `هُوَ الْحَيُّ الْقَيُّومُ` | `هو` mubtada' | REVIEW-PASS | dua unsur khabar/ekspansi; bukan bentuk minimal dua unsur |
| 42:11 | `هُوَ السَّمِيعُ الْبَصِيرُ` | `هو` mubtada' | REVIEW-PASS | struktur pronominal jelas, tetapi khabar berlapis |
| 59:22 | `هُوَ اللَّهُ` | pronoun + nominal predicate | PASS-CANDIDATE | sangat pendek; perlu verifikasi dependency penuh pada ayat untuk pemotongan unit |

### Kesimpulan awal

K11 sangat viable, tetapi **pure two-element yield** tampak lebih kecil daripada jumlah ismiyyah isim zhahir. Banyak contoh Qurani segera memperluas khabar dengan unsur tambahan. Ini tidak menggugurkan K11, hanya mengharuskan minimal-unit extraction yang disiplin.

## 2. K12 — Khabar Jar–Majrur Sederhana

Target relation: `مبتدأ + خبر شبه جملة` dengan khabar berupa jar–majrur.

### Evidence awal

| Ref | Quranic unit | Target | Status | Notes |
|---|---|---|---|---|
| 2:10 | `فِي قُلُوبِهِمْ مَرَضٌ` | khabar muqaddam + mubtada' mu'akhkhar | PREMATURE | dhamir muttashil + idhafah; bukan K12 core |
| 2:7 | `عَلَىٰ أَبْصَارِهِمْ غِشَاوَةٌ` | شبه جملة + nominal | PREMATURE | dhamir muttashil/idhafah |
| 36:71 | `لَهُمْ فِيهَا مَنَافِعُ` | شبه جملة predicate | PREMATURE | preposition+dhamir dan pronoun suffix |
| 30:4 | `لِلَّهِ الْأَمْرُ` | khabar muqaddam + mubtada' | REVIEW-PASS | `لله` melibatkan lam attached to proper noun tetapi tidak dhamir; candidate kuat |
| 45:36 | `فَلِلَّهِ الْحَمْدُ` | khabar muqaddam + mubtada' | PREMATURE/REVIEW | prefiks `فـ` menambah dependency jika fa belum dipelajari |

### Kesimpulan awal

K12 secara dependency sangat kuat, tetapi banyak contoh natural Qurani memakai **preposition + attached pronoun** atau idhafah. Candidate seperti `لِلَّهِ الْأَمْرُ` penting karena menunjukkan bahwa bentuk core tanpa dhamir memang tersedia.

## 3. K13 — Maf'ul Bih Isim Zhahir Sederhana

Target relation: `فعل + فاعل + مفعول به ظاهر`, dengan target baru berupa objek eksplisit.

### Evidence awal

| Ref | Quranic unit | Target | Status | Notes |
|---|---|---|---|---|
| 2:31 | `عَلَّمَ آدَمَ الْأَسْمَاءَ` | verb + object(s) | PREMATURE | pola verba dengan dua objek/analisis kompleks |
| 2:51 | `اتَّخَذْتُمُ الْعِجْلَ` | object zhahir | PREMATURE | subject berupa suffix persona jamak; belum core K13 |
| 2:87 | `آتَيْنَا مُوسَى الْكِتَابَ` | object zhahir | PREMATURE | subject encoded suffix `نا`; possibly two-object/ditransitive behavior |
| 12:21 | `أَكْرِمِي مَثْوَاهُ` | object | PREMATURE | imperative + ya mukhatabah + attached pronoun in object phrase |
| 17:81 | `جَاءَ الْحَقُّ` | no object | NOT-TARGET | confirms need to distinguish K10 from K13 |
| 7:117 | `تَلْقَفُ مَا يَأْفِكُونَ` | object clause/maushul | PREMATURE | object not simple zhahir noun |
| 20:70 | `آمَنَّا بِرَبِّ هَارُونَ` | no direct object core | NOT-TARGET | prepositional complement rather than K13 target |

### Yield finding

K13 menunjukkan **prematurity burden lebih tinggi dari dugaan**. Banyak verba transitif Qurani yang mudah ditemukan membawa:

- fa'il berupa suffix/dhamir;
- dua objek;
- object pronoun;
- object clause/maushul;
- idhafah di dalam object NP;
- derivational verb forms dan tambahan struktur lain.

Ini tidak berarti K13 salah, tetapi menunjukkan bahwa **clean core `فعل + فاعل ظاهر + مفعول ظاهر` mungkin tidak sebanyak idhafah sederhana**.

**Status:** NEEDS MORE SEARCH BEFORE FREEZE.

## 4. K14 — Idhafah Dua Isim Sederhana

Target relation: `مضاف + مضاف إليه` dengan dua isim zhahir dan tanpa suffix pronominal.

### Evidence awal

| Ref | Quranic unit | Target | Status | Notes |
|---|---|---|---|---|
| 1:2 | `رَبِّ الْعَالَمِينَ` | idhafah | PASS-CANDIDATE | dua isim zhahir; unit sangat jelas |
| 1:4 | `مَالِكِ يَوْمِ الدِّينِ` | nested idhafah | PREMATURE untuk core | ada idhafah bertingkat: `مالك يوم` + `يوم الدين` |
| 2:7 | `أَبْصَارِهِمْ` | idhafah pronominal | PREMATURE | dhamir muttashil |
| 2:22 | `ثَمَرَاتٍ رِزْقًا` | bukan idhafah | NOT-TARGET | perlu hindari false positive adjacency |
| 106:3 | `رَبَّ هَٰذَا الْبَيْتِ` | idhafah dengan isim isyarah expansion | PREMATURE | musyar ilaih/isyarah belum tersedia |
| 110:1 | `نَصْرُ اللَّهِ` | idhafah | PASS-CANDIDATE | dua isim zhahir, sangat bersih |
| 111:1 | `يَدَا أَبِي لَهَبٍ` | idhafah | PREMATURE | mutsanna + nested name phrase |

### Kesimpulan awal

K14 mempunyai **clean anchor yang sangat kuat** seperti:

- `رَبِّ الْعَالَمِينَ`
- `نَصْرُ اللَّهِ`

Idhafah juga lebih lokal daripada maf'ul bih dan tidak memerlukan recovery subject. Prematurity terutama muncul karena nested idhafah, dhamir suffix, demonstrative phrase, atau bilangan/mutsanna.

**Status:** VERY STRONG.
