# Clean Bank + Stress Test K66 — Explicit Purpose / Goal Relation v0.1

**Status:** PRE-FREEZE STRESS TEST  
**Baseline:** K1–K65 DRAFT-FROZEN.

## Operation under test

Learner identifies a validated Qur'anic construction where an action/proposition A is explicitly oriented toward an intended goal B.

Core representation:

`ACTION / PROPOSITION A → PURPOSE / GOAL B`

The learner must identify both the governed action and the intended end.

## Clean-bank admission rules

PASS only when:
- A is overt and locally identifiable;
- B is overt enough to state the intended goal;
- the construction is independently validated as purposive;
- all morphology/mood required to read the form is already mastered ≤ K65;
- no new hidden `أن` reconstruction is required;
- no new naṣb rule is required;
- cause and result readings are not serious competitors;
- one purposive dependency solves the item.

## Evidence classes

### PASS-A — direct purpose
Clear action + overt purposive construction + explicit goal.

### PASS-B — cumulative-clean purpose
Additional mastered syntax occurs inside A or B, but the action→goal relation remains local and transparent.

### REVIEW-CAUSE
The construction can be understood as reason/cause rather than intended goal without additional disambiguation.

### REVIEW-RESULT
The second span looks like consequence rather than intended end.

### REVIEW-MOOD
Purpose is semantically clear, but explaining the morphology would require a new mood mechanism.

### PREMATURE
- purpose inferred only from tafsir or world knowledge;
- ellipsis reconstruction;
- hidden governor required as a new operation;
- several goals in one item;
- long-distance scope;
- rhetorical purpose requiring advanced balaghah.

## Stress test 1 — Distinctness from K64

K64 answers:
`why is A so?` → B supplies reason/grounds.

K66 answers:
`for what intended end is A done?` → B supplies goal.

A reason can already be true when A occurs; a goal is prospective/intended and need not be realized. This supports a distinct semantic operation.

## Stress test 2 — Distinctness from K63

K63 identifies what follows as a result/consequence.

K66 identifies what is aimed at. Result and purpose may coincide in some real-world cases, but the learner must classify the discourse relation encoded in the occurrence, not the eventual outcome.

## Stress test 3 — Does every purpose marker need a new K?

No. Marker diversity remains application breadth. Separate K numbers are not justified for `لـ`, `كي`, or other purposive forms if the learner operation remains:

`identify A → identify goal B`.

## Stress test 4 — Does K66 duplicate K53 hidden `أن`?

No. K53 reconstructs a hidden grammatical governor. K66 identifies a semantic purpose relation. Any occurrence that requires hidden-`أن` reconstruction as a new step is excluded from core K66 evidence.

## Assessment design

Core prompt:

`ما الفعل أو المعنى الذي ذُكرت له الغاية؟ وما الغاية المقصودة؟`

Expected response identifies A and states B as the intended purpose/goal.

## Verdict

**PASS WITH STRICT MORPHOLOGY CONTAINMENT.**

K66 is independently assessable when the purpose relation is overtly signaled and all form-level prerequisites are already mastered.

## Freeze recommendation

> **K66 — Mengenali relasi tujuan/غاية antara suatu tindakan atau proposisi Qurani dan tujuan yang dinyatakan secara eksplisit melalui konstruksi yang tervalidasi.**
