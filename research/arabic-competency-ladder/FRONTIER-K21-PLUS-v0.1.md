## 2. Head-to-Head: Object Pronoun vs Hidden Subject

### A. Dhamir muttashil sebagai maf'ul bih

Dependencies:
- K15 recognition attached pronoun;
- K14 maf'ul bih zhahir sebagai fungsi objek;
- K6/K7 verb recognition;
- subject dapat dibatasi pada bentuk yang sudah dikenal.

Kekuatan:
- fungsi baru sangat spesifik;
- bentuk surface terlihat;
- integrasi langsung K14 + K15;
- dapat difilter ke verba sederhana dengan satu object suffix.

Beban:
- beberapa verba membawa subject suffix sekaligus;
- dua object suffix/object structure harus ditahan;
- quoted/object clause tidak masuk.

**Strength:** VERY HIGH.

### B. Fa'il mustatir dasar

Dependencies:
- K6/K7 verb recognition;
- K10 fi'il + fa'il relation;
- pemahaman person/number/gender pada verb form;
- inference bahwa fa'il tidak selalu muncul sebagai token independen.

Kekuatan:
- sangat penting dan sangat produktif dalam Qur'an.

Beban:
- unsur target tidak terlihat sebagai token;
- inference morphology-to-syntax lebih abstrak;
- berpotensi bersinggungan dengan dhamir/person system yang belum digeneralisasi penuh.

**Strength:** HIGH, tetapi lebih abstrak daripada object suffix.

### Result

**K21-CAND = dhamir muttashil sebagai maf'ul bih** lebih kuat daripada fa'il mustatir.

## 3. Search for a Lighter Intervening Competency

### Candidate: jar–majrur sebagai pelengkap fi'il sederhana

Dependencies:
- K9/K20 jar–majrur;
- K6/K7 verb recognition;
- K10 verbal relation.

Contoh pedagogis dapat berupa pola:
`فعل + جار ومجرور`
atau
`فعل + فاعل + جار ومجرور`
selama target attachment dapat ditentukan tanpa struktur lebih tinggi.

Ini merupakan integrasi kompetensi yang sudah tersedia, bukan kategori baru.

**Strength:** VERY HIGH.

### Comparison with K21 object suffix

- verb + PP: dependency lokal tetapi attachment analysis diperlukan;
- object suffix: fungsi maf'ul sudah ada K14 dan suffix recognition K15, sehingga integrasinya sangat langsung.

**Preliminary:** object suffix tetap sedikit lebih kuat untuk K21; verbal PP sangat kuat sebagai K22 candidate.

## 4. Recognition Candidates: Isim Isyarah and Isim Maushul

### Isim isyarah recognition

Surface forms seperti `هذا`, `هذه`, `ذلك`, `تلك` dapat diajarkan sebagai REC sebelum fungsi sintaksis kompleks.

Dependency sangat rendah, tetapi secara sequence pedagogis perlu diputuskan apakah recognition category baru harus menyela ekspansi relasional yang sudah terbuka.

**Strength:** HIGH REC.

### Isim maushul recognition

Forms seperti `الذي`, `التي`, `الذين` dapat dikenali sebagai REC, tetapi penggunaan penuh membutuhkan shilah maushul, yang jelas lebih kompleks.

**Strength:** HIGH REC; syntactic use later.

5. **K25-CAND** — fa'il mustatir dasar

## 6. Why Fa'il Mustatir Moves Down

Fa'il mustatir tetap fundamental, tetapi:
- targetnya inferred, bukan overt;
- perlu abstraction dari morphology ke syntax;
- ada beberapa kompetensi overt yang dependency-nya lebih pendek dan clean-example yield-nya lebih mudah dikontrol.

Karena prinsip tangga adalah mudah → sulit dengan cumulative-only evidence, fa'il mustatir tidak perlu dipaksa segera setelah K20.

## 7. Evidence Rules for K21–K25

### K21
- suffix harus berfungsi object langsung;
- bukan possessive/prep-object;
- single-object core;
- subject structure harus <= K21.

### K22
- PP harus benar-benar attach pada verb/verb phrase target;
- nominal khabar use tidak dihitung K22;
- nested PP/coordination ditahan.

### K23
- recognition only;
- fungsi mubtada'/khabar/badal belum otomatis diajarkan.

### K24
- recognition only;
- shilah maushul belum masuk.

### K25
- active verb only;
- hidden subject dapat dipulihkan secara dasar;
- passive dan embedded complexity ditahan.
