# Clean Bank + Stress Test K53 — Hidden `أن` v0.1

**Status:** PRE-FREEZE STRESS TEST  
**Baseline:** K1–K52 DRAFT-FROZEN.

## Operation under test

In a tightly validated Qur'anic construction, learner recognizes that a familiar mudhari‘ is mansūb although no overt `أن` appears, and reconstructs **one locally licensed hidden `أن`** as the governing element.

Core reasoning:

`validated trigger/context → [أن] مقدرة → فعل مضارع منصوب`

The new operation is **single-governor reconstruction**.

## Trigger-family question

Traditional grammar licenses hidden `أن` in more than one environment. K53 must not become an inventory of all such environments.

### Internal staging rule

Different triggers may remain variants inside K53 only when learner action is unchanged:
1. recognize an already-validated trigger configuration;
2. insert one hidden `أن`;
3. connect it to the following mudhari‘ nasb.

If a trigger requires a new semantic relation or a new syntactic theory merely to license the ellipsis, it is not core K53 evidence.

## Evidence classes

### PASS-A — maximally controlled trigger
- trigger/configuration overt and already interpretable;
- hidden `أن` analysis stable;
- one mudhari‘ target;
- nasb effect analyzable from K52;
- exactly one reconstruction.

### PASS-B — alternate trigger, same operation
A different trigger family is acceptable only if no new learner operation is required beyond the same one-step reconstruction.

### REVIEW-TRIGGER
Hidden `أن` may be grammatically standard, but the trigger itself requires a rule not yet mastered.

### REVIEW-ANALYSIS
Competing analyses make the ellipsis unsuitable for a clean competency example.

### PREMATURE
- multiple ellipses;
- complex coordination dependency;
- semantic licensing that itself needs a new competence;
- advanced weak-verb/nūn-deletion interaction obscuring the target;
- cases taught mainly through memorized exception lists.

## Stress test 1 — Are trigger types separate competencies?

**Not automatically.** Surface trigger diversity does not justify K fragmentation when the mental operation remains `trigger → restore one أن → explain nasb`.

However, K53 core should start with **one maximally transparent trigger family**. Other trigger families enter only after independent validation as application breadth.

## Stress test 2 — Does K53 secretly teach all `أن المضمرة` rules?

No. The learner is not asked to list where `أن` is obligatory or permissible, distinguish every traditional subcategory, or generate novel examples from a complete rule table.

K53 is occurrence-specific reconstruction.

## Stress test 3 — Distinctness from K52

K52:
`overt governor → nasb effect`.

K53:
`validated context but no overt governor → reconstruct one governor → nasb effect`.

The reconstruction step is genuinely new and independently assessable.

## Stress test 4 — Morphology containment

Initial K53 examples should prefer transparent fatḥah already mastered in K52. Nasb via `حذف النون` may be used only later as cumulative transfer and should not be necessary to establish K53.

## Assessment design

Core prompt:

`ما العامل المقدّر قبل الفعل المضارع؟ وما أثره؟`

Expected response identifies a locally licensed hidden `أن` and connects it to nasb. Full traditional taxonomy is not required.

## Verdict

**PASS WITH SINGLE-TRIGGER CORE + CONTROLLED EXPANSION.**

K53 remains one competence if trigger diversity is treated as evidence/application breadth rather than bundled rule memorization.

## Freeze recommendation

> **K53 — Merekonstruksi satu `أن` مقدرة yang tervalidasi sebagai nāṣib bagi fi‘il mudhari‘ dalam konstruksi Qurani terkontrol.**
