# E2 CLEAN-BANK EXPANSION — K26–K37 — BATCH 01 v1.0

**Status:** ACTIVE / FIRST PROMOTION BATCH  
**Architecture:** FROZEN K01–K65  
**Goal:** promote recognition nodes K26–K37 from E1/E1+ toward E2 using several clean occurrences and explicit multifunctionality controls.

## Method

A recognition competency reaches E2 only when:
1. more than one Qur'anic occurrence/form supports the target family;
2. the learner operation remains recognition, not premature syntactic analysis;
3. homographic or multifunctional forms are controlled;
4. target spans can be isolated without importing later competencies.

## K26–K37 batch posture

### K26 — interrogative recognition
**Decision: E2 candidate.**

Evidence families already established in the frozen discovery process are retained. A particularly useful controlled occurrence is QS 2:255 `مَنْ ذَا الَّذِي`, where `مَنْ` is explicitly interrogative while `ذَا` is demonstrative and `الَّذِي` relative. This is valuable for head-to-head discrimination, but the full phrase is structurally complex and therefore not by itself sufficient as a clean beginner item.

### K27 — negation recognition
**Decision: E2 candidate.**

QS 2:255 contains repeated `لَا`, including `لَا تَأْخُذُهُ` and `وَلَا يُحِيطُونَ`. These give repeated occurrence evidence, but family diversity beyond `لا` remains desirable before formal E2 promotion.

### K28 — vocative recognition
**Decision: hold E1.**

Need several clean `يَا + addressee` occurrences with ambiguity controls and without requiring advanced parsing.

### K29 — imperative recognition
**Decision: hold E1.**

Need diversified imperative forms whose recognition does not depend on advanced morphology.

### K30 — prohibitive `لا` recognition
**Decision: E2 candidate.**

Must remain distinct from generic negation K27. Promotion requires multiple occurrences where `لا` is specifically prohibitive with jussive imperfect, not merely negative.

### K31 — hamzat al-istifham recognition
**Decision: E2 candidate.**

Promotion requires several genuine interrogative hamzah occurrences and explicit exclusion of lexical/root hamzah.

### K32 — `قد` recognition
**Decision: hold E1.**

Need clean occurrences across controlled verbal environments. Recognition only; aspectual interpretation belongs to later transfer.

### K33 — `إنّ` recognition
**Decision: E2 candidate.**

Recognition bank is structurally promising, but E2 requires several normalized occurrences and exclusion from other orthographic `إن` functions.

### K34 — `إلا` recognition
**Decision: PROMOTE TO E2.**

QS 2:255 alone provides multiple occurrence-level functions:
- `إِلَّا هُوَ` — exceptive environment;
- `إِلَّا بِإِذْنِهِ` — exceptive environment;
- `إِلَّا بِمَا شَاءَ` — restriction environment.

The same surface marker is therefore repeatedly recognizable while its later syntactic/semantic functions remain deliberately deferred. This is exactly the recognition-level distinction required by K34.

**New maturity: E2.**

### K35 — `ليس` recognition
**Decision: hold E1.**

Need several normalized occurrences; no promotion based on lexical familiarity alone.

### K36 — `لو` recognition
**Decision: hold E1.**

Need diversified conditional/counterfactual occurrences while preserving recognition-only scope.

### K37 — `كان` family recognition
**Decision: E2 candidate.**

Family recognition is strong in the discovery artifacts, but promotion should demonstrate more than one member/form and keep syntactic governance for K40.

## Important control demonstrated by QS 2:255

The verse is especially useful for discrimination because it contains, in a compact environment:
- `هُوَ` detached pronoun;
- `إِلَّا` exceptive/restrictive marker;
- `مَا` relative pronoun;
- `مَنْ` interrogative noun;
- `ذَا` demonstrative;
- `الَّذِي` relative pronoun;
- `لا` negative particle;
- attached object and possessive pronouns.

The bank must not turn this density into one overloaded beginner item. Each K receives a minimal target span and later features are masked or excluded.
