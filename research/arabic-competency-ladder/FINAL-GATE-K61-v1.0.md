# FINAL GATE K61 v1.0

**Status:** DRAFT-FROZEN  
**Baseline:** K1–K60 DRAFT-FROZEN.

## Competency

**K61 — Mengenali `العائد` eksplisit di dalam `صلة الموصول` dan menghubungkannya kembali kepada `اسم الموصول` dalam konstruksi Qurani sederhana.**

## Learner operation

Given a validated relative construction, learner can:
1. identify the overt `اسم الموصول`;
2. locate its `صلة الموصول` using K60;
3. identify one overt resumptive pronoun inside the relative clause;
4. resolve that pronoun back to the relative antecedent.

## Included

- overt familiar relative marker;
- short, clear `صلة الموصول`;
- one overt resumptive pronoun;
- unique local antecedent;
- pronoun forms already familiar;
- cumulative analysis through K60.

## Excluded

- `العائد المحذوف`;
- multiple competing antecedents;
- long-distance discourse anaphora;
- nested relative clauses;
- multiple pronouns requiring advanced disambiguation;
- disputed resumptive analysis.

## Assessment prompt

`أين العائد في صلة الموصول؟ وعلى أي اسم موصول يعود؟`

Expected core response identifies the overt resumptive and its antecedent.

## Gate results

- distinctness from K60: PASS;
- explicit-reference resolution: PASS;
- antecedent uniqueness requirement: PASS;
- position anti-fragmentation: PASS;
- one-operation rule: PASS.

**Decision: K61 DRAFT-FROZEN.**

## Architectural significance

K60 → K61 moves from relative-clause structure to local textual cohesion:
- K60: identify the clause attached to the relative marker;
- K61: resolve the overt internal reference that reconnects that clause to its antecedent.

This creates a controlled bridge from syntax into anaphoric interpretation without yet introducing omitted reference elements.
