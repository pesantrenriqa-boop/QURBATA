# Clean Bank + Final Stress Test K41 — Fa'il Mustatir Dasar v0.1

**Status:** PRE-FREEZE RESEARCH  
**Baseline:** K1–K40 DRAFT-FROZEN.

## Target

K41 = mengenali fa'il mustatir dasar pada fi'il aktif sederhana, tanpa menjadikannya pelajaran tasrif penuh.

## Core operation

Learner determines that:
1. the verb is active and structurally simple;
2. there is no separate explicit fa'il in the target unit;
3. the fa'il slot is nevertheless filled implicitly;
4. the grammatical person/number is recoverable from already-mastered verbal morphology.

## Clean-bank classes

### PASS-A — Pure hidden-subject core

Use only occurrences where the hidden subject itself is the only new operation. The target unit should be short and free of later clause-linkage requirements.

### PASS-B — Cumulative clean

May include object, PP, adjective, conjunction, or other material already frozen through K40, provided none of it changes the hidden-subject inference.

### REVIEW-MORPH

Verb form requires a morphology distinction not yet explicit in the K1–K40 scope. Keep in corpus bank but do not count as core teaching evidence.

### REVIEW-REF

The grammatical person is clear but identifying the discourse referent would require broader context. This can support later reinforcement but not first-layer core.

### PREMATURE

Exclude from K41 core when the inference requires:
- passive analysis;
- silah maushul linkage;
- conditional protasis/apodosis;
- nested clause;
- advanced ellipsis;
- discourse-dependent zero argument beyond basic person recovery;
- full conjugational paradigm explanation.

## Stress tests

### 1. Explicit-fa'il confusion

If an explicit noun later in the unit is actually the verb's fa'il, the occurrence is not K41. Surface distance alone cannot justify hidden-subject analysis.

**Result:** enforce parser/occurrence-specific subject relation.

### 2. Attached subject vs hidden subject

Forms with overt suffixal subject morphology must not be mislabeled as mustatir if the subject is morphologically expressed. K41 targets unexpressed syntactic subject, not every non-nominal subject form.

**Result:** distinction required.

### 3. Imperative interaction

K26 already recognizes fi'il amr. Many imperatives involve understood second-person subjects. They may be strong K41 evidence only if morphology scope is already secure and no additional command-specific relation is required.

**Result:** allowed as later PASS-B/reinforcement; do not let imperative dominate core bank.

### 4. Mudhari' person-prefix ambiguity

A prefix can identify grammatical person without fully identifying discourse referent. K41 only requires grammatical-person recovery, not antecedent resolution.

**Result:** PASS where person is morphologically clear; REVIEW-REF where referent is context-heavy.

### 5. Clause-boundary leakage

If determining the subject requires knowing whether a following phrase belongs to a relative/conditional/subordinate clause, the example is premature.

**Result:** exclude from core.

## Dependency reversal check

No hard dependency was found requiring K42 silah-maushul analysis before basic hidden-subject inference. In the cleanest verbal patterns, K41 can be solved using only previously frozen morphology + verb-subject knowledge.

## Anti-tasrif boundary

K41 is not:
- memorizing all 14 conjugational slots;
- classifying all obligatory/permissible mustatir types;
- reconstructing discourse antecedents;
- learning every attached/hidden pronoun contrast at once.

It is a single operational skill: **detect and recover the basic hidden fa'il slot in a simple active verb occurrence**.

## Freeze recommendation

**PASS — READY FOR DRAFT-FREEZE**, provided final gate preserves:
- active-only scope;
- no explicit fa'il;
- subject truly unexpressed, not suffixally overt;
- grammatical person recoverable from prior morphology;
- no K42+ clause-linkage dependency.

## Next frontier

After freeze, open K42 evidence gate for `isim maushul + silah minimal`, with special attention to `عائد` and clause-boundary complexity.
