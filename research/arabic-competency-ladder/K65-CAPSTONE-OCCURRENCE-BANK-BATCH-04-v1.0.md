## Positive occurrence families

Target span combines conditional particle إن, jussive imperfect تطيعوا, overt object فريقا, relative pronoun الذين, and passive perfect أوتوا within the relative clause. This is a high-quality integration seed because the target relations are locally annotated and separable.
Pattern: CONDITION + MOOD + ARGUMENT + RELATIVE CLAUSE + PASSIVE.

P2 — conditional-result family
Select an occurrence where the condition and result are both locally segmentable and the result relation is explicitly represented. Do not score broader rhetoric. Pattern: CONDITION + RESULT + CLAUSE BOUNDARY.

P3 — relative-clause integration family
Select an occurrence with explicit REL token and locally bounded ṣilat al-mawṣūl, then add one already-mastered internal relation such as subject/object/passive. Pattern: RELATIVE + INTERNAL SYNTAX.

P4 — nominal dependency integration family
Select an occurrence combining a nominal predicate/apposition/possessive relation with a second already-frozen feature. Pattern: NOMINAL DEPENDENCY + MORPHOSYNTACTIC FEATURE.

P5 — adverbial integration family
Select a locally clear circumstance/purpose/cognate/comitative relation plus an independently identifiable verbal/argument feature. Pattern: ADVERBIAL DEPENDENCY + VERBAL SYNTAX.
