# Clean Bank K42 — Isim Maushul + Silah Minimal v0.1

**Status:** WORKING RESEARCH — PRE-FREEZE  
**Baseline:** K1–K41 DRAFT-FROZEN.  
**Target:** boundary/linkage only: `اسم موصول → صلة الموصول`.

## Core rule

K42 does not teach a full taxonomy of `عائد`. It tests whether the learner can identify the explicit isim maushul and delimit the minimal silah using only structures already available through K41.

## Evidence classes

### PASS-A
- isim maushul explicit;
- silah short and structurally simple;
- boundary clear;
- internal grammar ≤ K41;
- no new resumptive mechanism required for basic linkage.

### PASS-B
- same as PASS-A but with cumulative material already frozen;
- K41 fa'il mustatir may occur inside a short verbal silah if its morphology is already within scope.

### REVIEW-AID
- boundary is clear but explaining the internal link requires explicit analysis of `عائد` not yet taught.

### REVIEW-BOUNDARY
- maushul is clear but end of silah is not pedagogically obvious without higher clause analysis.

### PREMATURE
- nested relative clause;
- conditional relation;
- new nawasikh configuration;
- complex ellipsis;
- advanced resumptive deletion;
- other K43+ relation.

## Clean-bank findings

The strongest K42 examples are not necessarily the shortest ayat, but those where the relative head and completing clause form a transparent local unit. Verbal silah becomes substantially more usable after K41 because basic hidden-subject analysis is no longer a future dependency.

The bank therefore prioritizes:
1. explicit relative pronoun;
2. one short verbal or nominal completing unit;
3. no nested dependency;
4. no need to reconstruct an omitted `عائد`;
5. no need for discourse-level antecedent resolution.

## Distinctness test — should `عائد` become K43?

### Operation taught in K42
`Identify the relative head and delimit its silah.`

### Additional operation required for full `عائد` analysis
`Identify the element inside the silah that refers back to the maushul, including explicit pronoun, prepositional pronoun, object pronoun, or omitted resumptive relation.`

These are not the same operation.

Full `عائد` analysis can require:
- pronoun-function discrimination;
- object/prepositional relations;
- omission/recovery;
- agreement and reference;
- sometimes clause-internal parsing beyond simple boundary recognition.

### Decision

`عائد` is **pedagogically distinct enough to remain a separate later candidate**, but it should **not automatically become K43**. Before assigning a new K, compare it head-to-head with other post-K42 operations such as emphatic lām and simple conditional linkage.

Thus:
- K42 remains atomic as **maushul→silah boundary/linkage**;
- `عائد` analysis is locked;
- evidence requiring full `عائد` explanation does not count toward K42 core quota.

## Stress test

No dependency reversal was found that forces full `عائد` analysis before boundary recognition. The learner can first learn to see:

`الذي / التي / الذين ...` → `صلة الموصول`

and only later analyze the resumptive mechanism inside that silah.

## Freeze recommendation

K42 is eligible for DRAFT-FREEZE if the final gate preserves:
- boundary/linkage-only target;
- REVIEW-AID exclusion from core evidence;
- no nested relative clauses;
- cumulative-only internal grammar through K41;
- no forced numeric quota.

## Next frontier

After K42 freeze, run head-to-head among:
- explicit/simple `عائد` analysis;
- emphatic lām in clean `إنّ` constructions;
- simple conditional relation;
- other corpus-revealed structural operations.
