# Evidence Gate K45 — Basic Omitted `عائد` v0.1

**Status:** WORKING RESEARCH — EVIDENCE GATE  
**Baseline:** K1–K44 DRAFT-FROZEN.

## K45 target

Learner can detect, in a validated simple `اسم موصول + صلة` construction, that the resumptive relation expected from K43 is **not overtly expressed**, and can recover only its basic local syntactic slot.

Core operation:

`اسم موصول` → `صلة` → expected return relation is absent on surface → recover one local slot

This is the first deliberately reconstructive relative-clause operation in the ladder.

## Hard scope

PASS candidates must satisfy all of the following:
- explicit isim maushul;
- silah boundary already analyzable by K42;
- omitted resumptive relation is locally recoverable;
- only one missing resumptive slot is needed;
- recovered role belongs to a relation already mastered before K45;
- no nested relative clause;
- no conditional linkage;
- no disputed multi-analysis;
- no additional ellipsis required.

## Evidence classes

### PASS-A — one-slot local recovery
The omitted resumptive is recoverable from a simple, stable structure with only one plausible pedagogical reconstruction.

### PASS-B — cumulative clean
Additional material may appear only when every other operation is already ≤ K44.

### REVIEW-ROLE
The omission is likely, but the recovered role itself would require a new syntactic relation.

### REVIEW-ANALYSIS
More than one plausible reconstruction or grammatical analysis exists; do not use as core teaching evidence.

### REVIEW-BOUNDARY
The relative-clause boundary is not independently obvious enough for the learner without higher clause parsing.

### PREMATURE
Reject from K45 core if it requires:
- multiple omitted elements;
- nested maushul structure;
- conditional linkage;
- advanced ellipsis theory;
- disputed reconstruction;
- later clausal-predicate analysis;
- other K46+ operation.

## Anti-leak rule

At K45, learner only needs to answer:

> `أين العائد المتوقع في هذه الصلة؟ وهل هو ظاهر أم محذوف؟ وما موقعه المحلي البسيط؟`

Do not require:
- full conditions of حذف العائد;
- detailed school-by-school nahwu disagreement;
- full i'rab reconstruction;
- all deletion patterns;
- rhetoric or stylistic reasons for omission.

## Evidence burden

K45 is riskier than K43 because the key evidence is absent from the surface. Therefore freeze requires stronger discipline:
1. occurrence analysis must be stable;
2. pedagogical reconstruction must be locally motivated;
3. only one omitted slot is introduced;
4. no higher competence is needed to justify the reconstruction;
5. quality outranks quantity.

## Freeze threshold

Do not freeze based on a numeric quota alone. K45 freezes only if a structurally diverse bank proves that omitted resumptive recovery can be taught as one repeatable operation rather than as a collection of exceptional nahwu cases.

## Stress-test question

If many candidate occurrences require advanced deletion rules or competing parses, K45 must be **reordered later** and the next lighter structural candidate should take the slot.
