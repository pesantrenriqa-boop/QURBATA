# CLEAN BANK + STRESS TEST K63 — Explicit Result / Consequence Relation v0.1

**Status:** PRE-FREEZE STRESS TEST  
**Baseline:** K1–K62 DRAFT-FROZEN.

## Operation under test

Learner identifies a directed result relation between two already-analyzable Qur'anic propositions when an overt, occurrence-specifically validated linker marks proposition B as consequence/result of proposition A.

Core representation:

`[Proposition A] → [overt validated result linker] → [Proposition B = RESULT]`

The new learner operation is **result/consequence classification**, not particle taxonomy.

## Core admission rule

A surface marker does not qualify by form alone. In particular, `ف` is admitted only after the occurrence has already been filtered against competing functions such as:
- `فاء جواب الشرط`;
- simple sequencing;
- discourse continuation;
- explanatory/other fā’ functions.

The learner should not need to solve that taxonomy inside K63.

## PASS requirements

- both A and B are overt proposition spans;
- both spans are analyzable using ≤ K62;
- connector/linker is overt;
- its resultative/consecutive function is stable in the occurrence;
- B can be stated as the outcome/consequence of A;
- temporal succession alone is insufficient;
- no hidden proposition or omitted governor is required;
- no second new semantic relation competes.

## Evidence classes

### PASS-A — maximally explicit result
A, linker, and B are all overt; B is unambiguously the result of A.

### PASS-B — cumulative-clean result
Internal clause complexity is already mastered and does not obscure A→B.

### REVIEW-MARKER
The result reading is plausible but identifying the connector's exact function requires a new particle-disambiguation lesson.

### REVIEW-SEQUENCE
B follows A temporally, but causal/resultative interpretation is not sufficiently distinct from K59 sequencing.

### REVIEW-CONDITION
The relation is essentially condition→response already covered by earlier competencies rather than an independent result relation.

### PREMATURE
- implicit causality without overt linker;
- long-distance discourse causality;
- tafsir-dependent causal inference;
- multiple possible antecedent propositions;
- ellipsis plus result inference in one item.

## Stress test 1 — Distinctness from K59

K59 asks:
`Which event/proposition comes later?`

K63 asks:
`Which proposition is presented as the result/consequence of the other?`

A sequence can exist without a result relation; therefore K63 is not reducible to K59.

## Stress test 2 — Distinctness from conditional structure

Condition→response is a specific syntactic dependency already represented earlier. K63 does not absorb those items merely because the response may be a semantic consequence.

An occurrence passes K63 only when result/consequence is independently teachable as the target discourse relation.

## Stress test 3 — Can `ف` be the core label?

No. K63 remains relation-centered. `ف` may provide evidence in selected occurrences, but the competency name must not become “recognize resultative fā’.” This prevents particle-inventory fragmentation.

## Stress test 4 — One-operation rule

Core assessment must be solvable after marker function has been prevalidated. The learner's new task is only:

`A → identify B as RESULT of A`.

If a student must first choose among several fā’ categories, the item is above core K63.

## Yield policy

No artificial numeric quota. Evidence quality outranks quantity. A small clean bank is preferable to a larger ambiguous bank.

## Verdict

**PASS WITH STRICT PREVALIDATED-MARKER POLICY.**

K63 is sufficiently distinct and teachable if it is defined as a discourse-semantic result relation and ambiguous marker classification is excluded from the learner task.

## Freeze recommendation

> **K63 — Mengenali relasi hasil/akibat antara dua proposisi Qurani yang sudah dapat dianalisis melalui marker eksplisit yang telah tervalidasi, dengan menetapkan proposisi kedua sebagai hasil/konsekuensi dari proposisi pertama.**

## Next frontier

After freeze, rescan K64 across:
- explicit cause/reason relation (inverse direction of result);
- purpose/goal relation with an overt marker;
- omitted `العائد` only if a low-dependency subtype is isolated;
- other discourse relations with overt evidence.

Do not automatically make every `ف` function a new K.
