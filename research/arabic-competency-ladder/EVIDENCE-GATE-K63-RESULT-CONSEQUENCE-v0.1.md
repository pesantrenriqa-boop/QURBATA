# EVIDENCE GATE K63 — Explicit Result / Consequence Relation v0.1

**Status:** ACTIVE EVIDENCE GATE  
**Baseline:** K1–K62 DRAFT-FROZEN.

## Candidate

> **K63-CAND — Mengenali relasi hasil/akibat antara dua proposisi Qurani yang sudah dapat dianalisis melalui marker eksplisit yang tervalidasi sebagai penanda consequence/result.**

## New learner operation

The learner must move beyond detecting linkage and identify a directed semantic relation:

`Proposition A → RESULT/CONSEQUENCE → Proposition B`

B is interpreted as the result/consequence of A in the validated occurrence.

## Critical containment rule

K63 is **not** “recognize `ف`.” Surface `ف` alone is insufficient evidence because Qur'anic fā’ is multifunctional.

A core item passes only after the marker/function has been externally validated so that the learner is not simultaneously required to solve particle-function ambiguity.

## PASS requirements

1. both proposition spans are analyzable using ≤ K62;
2. relation marker is overt;
3. marker is independently validated as result/consequence in the occurrence;
4. proposition B is a clear consequence/result of proposition A;
5. no conditional-response classification is required as a new operation;
6. no temporal-vs-causal ambiguity remains;
7. no omitted proposition is needed;
8. one semantic relation is sufficient to solve the item.

## Evidence classes

### PASS-A — explicit consequence
A and B are overt, marker is overt, and B is unambiguously presented as consequence/result.

### PASS-B — cumulative-clean complexity
One proposition contains previously mastered internal syntax, but the A→B result relation remains local and clear.

### REVIEW-FA
`ف` is overt but deciding which fā’ function applies is itself nontrivial.

### REVIEW-SEM
A result reading is plausible but temporal succession or discourse continuation competes seriously.

### REVIEW-COND
The construction is tightly bound to condition→response already covered in earlier competencies and does not independently evidence K63.

### PREMATURE
- implicit causality with no overt marker;
- multiple possible result sources;
- long discourse inference;
- rhetorical inference requiring tafsir rather than linguistic relation recognition;
- simultaneous ellipsis reconstruction.

## Distinctness

### vs K58
K58: `A ↔ B` as overt coordination.

K63: `A → B` where B is interpreted as consequence/result.

### vs K59
K59 asks **what comes after what** in a validated temporal sequence.

K63 asks **what follows as a result of what**. Mere chronological order does not pass.

### vs K62
K62 identifies contrast/correction.

K63 identifies consequence/result. The semantic relation is different and directionally causal/resultative.

### vs conditional response
A conditional response may semantically be a consequence of a condition, but occurrences whose only analysis is condition→response remain evidence for the earlier conditional competencies. K63 requires a clean result relation that is independently assessable as discourse-semantic consequence.

## Marker policy

No marker receives automatic ownership of K63. Marker forms are implementation evidence, not the competency itself.

Core bank should prioritize occurrences where grammatical annotation/standard analysis strongly fixes a resultative/consecutive function. Ambiguous `ف` stays outside the bank.

## Assessment prompt

`ما العلاقة بين المعنى الأول والثاني؟ وأيهما نتيجة للآخر؟`

Expected response identifies proposition B as result/consequence of proposition A and points to the overt validated linker.

## Gate verdict

**CONCEPTUAL DISTINCTNESS: PASS.**  
**MARKER AMBIGUITY RISK: HIGH BUT CONTAINABLE.**

K63 can proceed only with a strict clean-bank policy. If the Qur'anic corpus does not yield enough unambiguous overt occurrences under this policy, K63 must be deferred rather than weakened.
