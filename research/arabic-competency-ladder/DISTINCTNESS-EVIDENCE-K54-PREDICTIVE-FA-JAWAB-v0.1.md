# Distinctness + Evidence Gate K54 — Predictive `فاء جواب الشرط` v0.1

**Status:** WORKING RESEARCH — DISTINCTNESS/EVIDENCE GATE  
**Baseline:** K1–K53 DRAFT-FROZEN.

## Candidate K54

Learner can **predict**, in one tightly controlled response type, that a simple `جواب الشرط` requires an overt `فـ` before the response, rather than merely recognizing the `فـ` after seeing it.

This is deliberately narrower than the traditional full rule set for `اقتران جواب الشرط بالفاء`.

## Distinctness from K48

K48 asks:

> `أين فاء جواب الشرط؟`

K54 asks:

> `قبل أن تنظر إلى الفاء: هل هذا النوع من الجواب يحتاج إلى الفاء؟ ولماذا ضمن هذا النمط المحدود؟`

Thus the learner operation changes from **classification of an overt marker** to **prediction from response structure**.

## Anti-list principle

K54 fails if success depends on memorizing a heterogeneous list of response types with no shared learner operation.

Therefore core K54 must start with **one structurally transparent response family only**.

A second family may enter only if the same abstraction transfers cleanly.

## Preferred core test family

Provisional first family: **nominal-sentence response (`جملة اسمية`)** in a validated conditional construction.

Why this family:
- response clause type is structurally recognizable from earlier nominal-clause competencies;
- the learner does not need advanced morphology to identify it;
- prediction can be phrased structurally: this response is not a plain jussive verbal answer, so it is introduced with response fā’ in the validated pattern.

This wording is pedagogical and occurrence-specific; it does not claim the full traditional rule inventory has been mastered.

## Evidence classes

### PASS-A — nominal response, explicit fā’
- conditional boundary already K47;
- response is clearly a simple nominal sentence;
- `فـ` is overt and validated as `فاء جواب الشرط`;
- all internal grammar ≤ K53;
- learner can classify the response type before focusing on the fā’.

### PASS-B — same predictive rule, cumulative-clean
Additional material is allowed only if it does not add a second reason for fā’ or obscure the response type.

### REVIEW-RULE
Occurrence has fā’ but explaining its presence requires a different traditional subrule from the selected core family.

### REVIEW-BOUNDARY
Response type or response boundary is not independently clear.

### PREMATURE
- multiple competing reasons for fā’;
- oath/condition competition;
- omitted answer;
- nested conditional;
- advanced response types whose classification itself is new;
- exceptions or disputed analysis.

## Predictive assessment

Preferred item design:
1. show/identify the condition and the structural type of the upcoming response;
2. ask whether the response should be introduced with `فـ` under the validated pattern;
3. then reveal/locate the overt `فـ` in the Qur'anic occurrence.

This prevents K54 from collapsing back into K48 recognition.

## Anti-list stress test

### Test A — one family only
**PASS.** A nominal-response family creates a coherent predictive operation.

### Test B — bundle all traditional categories immediately
**FAIL.** Combining nominal, imperative, negative, جامد, لن/قد/سين/سوف, etc. would convert K54 into rule-list memorization.

### Test C — add families later as mastery breadth
**PASS CONDITIONALLY.** Only when each added family is already structurally recognizable and the learner is transferring the same prediction operation.

## Distinctness verdict

**PASS, but only under a single-family core.**

K54 deserves a separate competency if it remains predictive and structurally restricted. It should not be frozen as 'memorize all cases requiring fā’'.

## Provisional K54 definition

> **K54 — Memprediksi kebutuhan `فاء جواب الشرط` pada satu tipe jawab syarth yang sangat transparan (core awal: jumlah ismiyah), lalu memverifikasinya pada occurrence Qurani tervalidasi.**

## Freeze criteria

K54 may freeze only if:
1. enough clean nominal-response occurrences validate the pattern;
2. learner can classify the response as nominal using earlier competencies;
3. prediction can be made before marker recognition;
4. no heterogeneous rule list is required;
5. K48 remains necessary but not sufficient.

## Next

Build clean-bank + stress-test for the nominal-response core. If yield or structural purity is weak, reject/reorder K54 rather than broadening the rule list.
