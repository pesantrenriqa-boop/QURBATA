# Evidence Gate K56 — Raf‘ by `ثبوت النون` v0.1

**Status:** WORKING RESEARCH — EVIDENCE GATE  
**Baseline:** K1–K55 DRAFT-FROZEN.

## K56 target

Learner recognizes a familiar nūn-bearing mudhari‘ pattern as marfū‘ by identifying **retention of the inflectional nūn (`ثبوت النون`)** as positive morphological evidence in a validated non-nasb/non-jazm environment.

Core reasoning:

`known nūn-bearing mudhari‘ + raf‘ environment → ن remains → ثبوت النون = علامة الرفع`

## Why K56 is distinct

K51 teaches deletion of the same inflectional nūn under jazm.
K56 reverses the comparison direction: the learner now uses **retention**, not deletion, as a positive mood sign.

This is not merely “nothing happened.” The retained nūn must be interpreted as grammatically meaningful evidence.

## PASS requirements

- target pattern is already familiar;
- expected nūn is overt;
- local environment is validated as raf‘;
- no active nāṣib/jāzim governs the form;
- no full five-verb paradigm is required;
- person/number morphology is not itself the target;
- surrounding syntax is cumulative-clean ≤ K55.

## Evidence classes

### PASS-A — direct retention contrast
Known nūn-bearing pattern, overt retained nūn, clear raf‘ environment.

### PASS-B — cumulative-clean occurrence
Additional material is allowed if it does not obscure the retained nūn or governor state.

### REVIEW-BASE
The form contains nūn, but learner would need a broader paradigm to know whether that nūn is the relevant inflectional one.

### REVIEW-GOV
Nūn is overt, but establishing raf‘ requires later syntax.

### PREMATURE
- full `الأفعال الخمسة` paradigm production;
- complex person/number derivation;
- ambiguous nūn identity;
- disputed governance;
- multiple simultaneous morphological operations.

## Positive-evidence gate

K56 passes only if assessment requires the learner to say, in effect:

> `هذه النون ثابتة في هذا الفعل، وثبوتها هنا علامة رفع.`

An answer such as “it is not deleted” is insufficient unless tied to the positive raf‘ function.

## Contrast map

- K51: jazm → `حذف النون`;
- K56: raf‘ → `ثبوت النون`.

The learner can therefore compare two states of the same familiar inflectional pattern without learning the full traditional paradigm at once.

## Anti-fragmentation

Do not create separate K numbers for each of the five surface person/number patterns. Those are application breadth. K56 is one learner operation: interpret retained inflectional nūn as the raf‘ sign.

## Freeze criteria

Freeze only if:
1. clean occurrences provide unmistakable retained nūn;
2. base-form familiarity can be controlled;
3. raf‘ environment is locally stable;
4. no full paradigm is needed;
5. learner operation remains distinct from K51 and K55.
