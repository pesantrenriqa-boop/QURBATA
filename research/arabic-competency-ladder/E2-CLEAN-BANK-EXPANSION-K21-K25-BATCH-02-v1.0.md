## K21 — attached pronoun as direct object

Existing anchor: `تَرَاهُمْ` — 48:29.

Additional clean occurrence:
- `تَأْخُذُهُ` — 2:255 — imperfect verb + attached `ـه` explicitly functioning as object pronoun.
- `يَئُودُهُ` — 2:255 — imperfect verb + attached `ـه` explicitly functioning as object pronoun.

Boundary control:
- contrast with `عِلْمِهِ` / `كُرْسِيُّهُ`, where `ـه` is genitive/possessive, not object;
- contrast with `لَهُ`, where pronoun is governed by a preposition.

**Verdict: K21 → E2.** The bank now contains multiple verb-host object suffixes and strong same-verse negative contrasts.

**Verdict: K22 remains E2 candidate.** Additional independent demonstrative forms are required before formal promotion.

## K23 — relative-pronoun recognition

Existing anchor: `الَّذِينَ` — 48:29.

Additional occurrence:
- `الَّذِي` — 2:255 — overt relative pronoun in `مَنْ ذَا الَّذِي يَشْفَعُ...`.
- `مَا` — 2:255 — relative-pronoun use occurs repeatedly, but `ما` is multifunctional and is retained as advanced diversity rather than the primary clean teaching form.

Boundary control:
- target is recognition of the relative-pronoun token only;
- delimiting the relative clause is K42;
- resolving the resumptive element is K43/K45.

**Verdict: K23 → E2.** Singular `الذي` and plural `الذين` provide meaningful form diversity.
