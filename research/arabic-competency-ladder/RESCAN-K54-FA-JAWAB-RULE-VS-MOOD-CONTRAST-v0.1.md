# Rescan K54 — `فاء جواب الشرط` Rule Generalization vs Mood-System Contrast v0.1

**Status:** WORKING RESEARCH — PRE-FREEZE  
**Baseline:** K1–K53 DRAFT-FROZEN.

## Purpose

Menentukan operasi baru paling ringan setelah K53 tanpa menjadikan ringkasan K lama sebagai K baru dan tanpa kembali ke urutan textbook tradisional.

## Candidate A — rule-level generalization for `فاء جواب الشرط`

### Existing foundation
- K47: identify simple condition→response relation;
- K48: identify overt `فاء جواب الشرط` occurrence-specifically.

### New operation
Move from occurrence recognition to **predictive generalization**: given a simple response-clause type already understood, judge whether the response is of a class that requires/strongly licenses `فـ` in the traditional construction.

### Dependency burden
Moderate–high:
- requires categorizing the response clause;
- traditional rule contains several response classes;
- risk of becoming a memorized list;
- some categories depend on constructions not yet uniformly frozen.

### Scope possibility
K54 could be restricted to **one maximally transparent response class** rather than the whole rule inventory. But then the question arises whether that is a genuinely new operation or merely one application subtype of K48.

**Judgement: distinct in principle, but risk of rule-list overload remains high.**

## Candidate B — explicit raf‘–nasb–jazm contrast on familiar mudhari‘

### Existing foundation
- K49–K51: staged jazm effects;
- K52: nasb with transparent fatḥah;
- K53: hidden nasb governor reconstruction.

### Proposed operation
Given controlled paired/triple forms of a familiar mudhari‘, classify the local mood state from its governing environment and surface ending.

### Anti-duplication issue
This may look like a consolidation layer rather than a new competence. If learner merely recalls K49–K53 side-by-side, no new operation exists.

A distinct operation would need to be **contrastive selection**:
- same lexical verb;
- different governing environments;
- learner determines which state applies and explains the contrast.

Yet this still appears to synthesize previously learned operations rather than introduce a new structural relation.

**Judgement: valuable mastery layer, but should NOT become K54.**

## Candidate C — explicit nasb with `حذف النون`

### Existing foundation
- K51: nūn deletion mechanism under jazm;
- K52: explicit nasb environment.

### New operation test
Mechanism is already known; only governor changes. This is transfer/application, not a new operation.

**Judgement: reject as new K.**

## Candidate D — new local governor-function distinction

Corpus may offer a lighter operation than broad fā’ rule generalization: recognize a specific overt particle/function whose classification changes the analysis of an already-known clause.

This must be discovered occurrence-first rather than invented to fill K54.

**Judgement: keep frontier open.**

## Decision

Do **not** assign K54 yet to mood consolidation or nasb `حذف النون`.

Current strongest named candidate remains:

**K54-CAND — restricted predictive generalization of `فاء جواب الشرط`, beginning with one structurally transparent response class only if distinctness survives evidence testing.**

However this candidate must pass a severe anti-list test. If the operation collapses into memorizing response categories, K54 should be reopened to another corpus-discovered local operation.

## K54 provisional learner operation

Given a simple conditional construction whose response-clause type is already analyzable, learner can judge whether that response type requires the response to be introduced by `فـ`, for one validated core response class.

## Hard exclusions

- full traditional inventory of all cases requiring fā’;
- nested conditionals;
- oath–condition competition;
- omitted jawab;
- response types requiring yet-unfrozen constructions;
- memorized exception lists.

## Evidence gate questions

1. Can one response class be taught as a real generalization rather than a list item?
2. Can the learner predict unseen examples within that class?
3. Is the response type itself fully analyzable with K1–K53?
4. Does K54 remain distinct from K48 occurrence recognition?

## Next

Open a distinctness/evidence gate for restricted `فاء جواب الشرط` rule generalization. If it fails, rescan corpus for a different local operation rather than forcing K54.
