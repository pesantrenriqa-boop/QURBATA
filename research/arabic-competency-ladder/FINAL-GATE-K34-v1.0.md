### Scope

- token `إِلَّا` diperlakukan sebagai unit lokal dan invariant;
- analisis jenis istitsna', mustatsna, i'rab, hasr, dan scope clause tetap dikunci.

### Evidence rules
- occurrence harus tervalidasi sebagai `إِلَّا` pada fungsi relevan;
- teaching set memprioritaskan konteks dengan dependency sekitar <= K34;
- struktur negasi + `إِلَّا` yang membutuhkan analisis tambahan boleh disimpan sebagai reinforcement/REVIEW, bukan core;
- seluruh ayat tetap disimpan sebagai reference metadata walau unit belajar hanya token/konteks minimal.

### Integrity result
Tidak ditemukan dependency reversal yang memaksa `لَيْسَ` atau `كَانَ` mendahului K34.

### Production boundary
Tidak mengubah REG-ARB-001, AR-STG-*, master jilid, halaman, atau assessment produksi.
