# Evidence Gate K53 — Hidden `أن` in Controlled Nasb v0.1

**Status:** WORKING RESEARCH — EVIDENCE GATE  
**Baseline:** K1–K52 DRAFT-FROZEN.

## K53 target

Learner can detect that a familiar `فعل مضارع` is in a validated nasb environment where the governing `أن` is **not overtly written**, and can reconstruct only that single hidden governor locally.

Core operation:

`validated trigger/context` → `(أن) مقدرة` → `فعل مضارع منصوب`

K53 therefore moves from **overt governor recognition** (K52) to **single-governor reconstruction**.

## Hard scope

PASS examples require:
- one locally recoverable hidden `أن` only;
- target verb already recognizable as mudhari‘;
- nasb effect already within K52-type morphology or another previously frozen pattern;
- no disputed grammatical analysis;
- no multiple hidden elements;
- no advanced rhetoric/discourse reconstruction;
- no broad taxonomy of all places where `أن` may be omitted.

## Evidence classes

### PASS-A — pure one-step reconstruction
- context strongly licenses hidden `أن`;
- only one governor is reconstructed;
- target verb and nasb effect are transparent;
- all visible syntax ≤ K52.

### PASS-B — cumulative-clean
Extra material is permitted only when already mastered and irrelevant to the core reconstruction.

### REVIEW-TRIGGER
The occurrence is traditionally analyzed with hidden `أن`, but identifying the trigger requires a new rule family not yet available.

### REVIEW-MORPH
Hidden `أن` is stable, but the target verb’s nasb realization exceeds current morphology scope.

### REVIEW-ANALYSIS
More than one serious grammatical analysis exists, or the pedagogical reconstruction would depend on a disputed parsing.

### PREMATURE
- multiple omitted governors/elements;
- nested clause dependence;
- advanced semantic licensing;
- omitted material beyond a single `أن`;
- full taxonomy of `أن المضمرة` conditions needed to solve the occurrence.

## Anti-leak rule

At K53, learner should only answer:

> `هل يوجد ناصب ظاهر؟ إن لم يوجد، فما العامل المقدر البسيط الذي يفسر نصب هذا الفعل؟`

Expected core insight: a single hidden `أن` explains the local nasb.

Do **not** require:
- memorizing every position of `أن` obligatory/optional omission;
- full traditional classification of particles before hidden `أن`;
- advanced semantic distinctions;
- complete nasb paradigm.

## Distinctness from K52

K52:
- governor visible;
- learner maps overt governor → visible nasb effect.

K53:
- governor absent;
- learner performs one local reconstruction before applying the same syntax→morphology link.

Thus the new operation is genuinely inferential rather than inventory-based.

## Freeze criteria

K53 can freeze only if:
1. occurrence bank contains stable, non-disputed hidden-`أن` examples;
2. one-step reconstruction is sufficient;
3. no new trigger taxonomy is silently imported;
4. target morphology remains ≤ K52 or otherwise previously frozen;
5. examples are teachable without converting K53 into a full chapter on `أن المضمرة`.

## Next

Build a curated bank grouped by trigger type, then stress-test whether multiple trigger families belong inside one K as internal variation or require later rule-generalization. If clean evidence is weak, reorder rather than force K53.
