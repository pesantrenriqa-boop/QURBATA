# STAGE–LEVEL DEPENDENCY & WORKLOAD AUDIT L01–L21 v1.0

Status: WORKING-FROZEN → VALIDATED FIRST PASS
Scope: canonical K01–K65
Purpose: validate the proposed 5-stage / 21-level architecture before final freeze and placement-test construction.

## Audit principles
1. A level may contain multiple competencies only when prerequisite order remains teachable.
2. No placement item may require an unintroduced higher-level feature to identify a lower-level competency.
3. Level workload is determined by learner operation, dependency density, error burden, and assessment observability—not raw K count alone.
4. Higher stages may contain denser K bundles because their operation is integrative rather than first recognition.
5. K65 remains a capstone and cannot be used to compensate for failure in prerequisite competencies.

## Validated architecture

### Stage 1 — Foundation Recognition
- L01: K01–K03
- L02: K04–K06
- L03: K07–K09
- L04: K10–K12
Gate: learner can recognize foundational categories and perform controlled discrimination without relying on advanced syntax.
Workload verdict: BALANCED.

- L12: K34–K36

Workload verdict: MODERATE-HIGH but coherent.

### Stage 4 — Complex Clause Integration
- L14: K40–K42

- L16: K46–K48
- L17: K49–K51
- L18: K52–K54
- L19: K55–K57
Gate: learner can process nested/complex clause relations, controlled ellipsis/reconstruction, and higher dependency interactions.
Workload verdict: HIGH but distributed across six levels. K45 retains teacher-review fallback where reconstruction is ambiguous.

### Stage 5 — Qur'anic Integration / Capstone
- L20: K58–K61
- L21: K62–K65
Gate: learner integrates multiple previously mastered operations in authentic Qur'anic spans while respecting semantic/discourse uncertainty.
Workload verdict: ACCEPTABLE ONLY AS INTEGRATIVE LEVELS. K58–K64 must not be taught as eight unrelated new rule units. L20–L21 require spiral retrieval from L01–L19.

## Dependency audit result
- No structural reason found to expand the architecture beyond 21 levels in first-pass design.
- No structural reason found to collapse levels below 21 before field testing.
- Stage boundaries S1/S2, S2/S3, S3/S4, S4/S5 are retained.
- L04, L10, L13, L19, L21 are designated stage checkpoints.
- Failure at a checkpoint triggers diagnostic descent to the nearest lower level; it does not automatically reset the learner to L01.
- Acceleration is permitted when mastery evidence confirms prerequisite competence.

## Workload controls for L20–L21
1. Each learning session targets one integrative operation, not all K in the level.
2. Authentic Qur'anic spans may instantiate several mastered K simultaneously.
3. Assessment separates structural recognition from semantic/discourse interpretation.
4. Ambiguous semantic/discourse cases are teacher-reviewed and excluded from automatic scoring unless the answer key is locally recoverable.
5. K65 is the final synthesis task and is scored only after K58–K64 prerequisites are demonstrated.

## Placement implications
Recommended adaptive routing checkpoints:
- CP1 = L04
- CP2 = L10
- CP3 = L13
- CP4 = L19
- CP5 = L21

Routing principle: start with discriminative checkpoints, then descend/ascend adaptively. The placement test therefore does not need 65 independent screening blocks.
