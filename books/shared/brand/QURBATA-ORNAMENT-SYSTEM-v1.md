# QURBATA Ornament System v1

Status: DESIGN SPECIFICATION — NOT YET APPLIED TO PRINT PAGES

## 1. Source and lineage

QURBATA Ornament System is a unit-level derivative of the RIQA Official Ornament System (RIOS), recovered from the official RIQA ornament/batik documentation.

Authoritative RIQA references:
- RIQA-EDUCATION-SYSTEM commit `37d5e4c2bc953c1b2fff419ae11816d5d5c05579`
- RIQA-EDUCATION-SYSTEM commit `7837ca1feb3da075e4a0dcb186787a08045f12d5`

QURBATA must remain visibly related to RIQA, but must not repeat the full RIQA batik field on educational pages.

## 2. Purpose

The ornament system is intended for:
- thin header separators;
- thin footer separators;
- chapter/page dividers;
- evaluation pages;
- cover/detail accents;
- watermark/light-pattern applications.

It must never compete visually with the participant-facing Qur'anic/Arabic learning material.

## 3. DNA extracted from RIOS

Only Secondary and Micro Ornament elements are used for ordinary QURBATA page furniture:
- horizontal base line;
- short 90-degree kufic turns;
- small roof/naungan-derived angular element;
- single tauhid dot as an optional focal accent;
- short vertical/horizontal connector modules;
- micro square/angle/line modules extracted from the RIQA kufic geometry.

The full Master Ornament must NOT be stamped repeatedly as a logo.

## 4. Visual language

### 4.1 Header
- very thin green line;
- one or two micro gold interruptions/markers;
- optionally one minimal secondary ornament near the center;
- no frame around the entire header;
- no heavy fill;
- no literal letter Q medallion.

### 4.2 Footer
- same visual family as header, but slightly more expressive;
- green base line + gold micro-ornament sequence;
- center may use an abstract kufic-derived connector/roof/tauhid-dot module;
- center must NOT be a literal `Q` unless separately approved;
- text may flank the center ornament:
  - left: `قُرْآنٌ · لُغَةٌ · أَدَبٌ`
  - right: `تَعَلَّمْ · اِعْمَلْ · عَلِّمْ`

## 5. Color direction

Derived from RIOS unit guidance:
- QURBATA primary: dark RIQA green;
- accent: gold;
- white/cream as page ground;
- monochrome variant allowed for low-cost print.

No additional palette is frozen in this version.

## 6. Geometry

QURBATA page ornament should inherit RIOS geometric discipline:
- primary angles: 90 degrees;
- optional diagonals: 45 degrees;
- line thickness consistent within each ornament instance;
- modules aligned on an internal grid;
- repeated elements must connect optically, not look like scattered icons.

## 7. Density

For learning pages use only LIGHT density.

Target visual proportion:
- ornament occupies no more than ~3–5% of page visual attention;
- participant-facing Arabic remains dominant;
- header/footer ornaments stay thin enough that they do not reduce Arabic font size.

## 8. Prohibited forms

- repeated RIQA/QURBATA logos as a pattern;
- literal Q medallion used only as decoration;
- floral or unrelated traditional ornament not derived from RIOS;
- thick decorative bands that reduce learning area;
- dense batik fields on ordinary exercise pages;
- changing the Arabic learning font merely to make ornament fit.

## 9. Header/footer relationship

Header = identity / orientation.
Footer = philosophy / visual signature.

They must share the same geometric DNA without being identical.

Proposed footer semantic pair:
- content identity: `قُرْآنٌ · لُغَةٌ · أَدَبٌ`
- learning cycle: `تَعَلَّمْ · اِعْمَلْ · عَلِّمْ`

## 10. Approval gate

This document defines design direction only.
No existing P001 visual freeze is replaced by this document.
Before application to QURBATA pages:
1. one header ornament prototype must be reviewed;
2. one footer ornament prototype must be reviewed;
3. only after user approval may the pattern be applied to P001 and subsequent pages.
