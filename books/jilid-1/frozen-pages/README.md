# QURBATA Jilid 1 Frozen Pages

Folder ini menyimpan sumber permanen setiap halaman yang sudah selesai dan disetujui.

Setiap halaman final memiliki folder sendiri: `P001`, `P002`, dan seterusnya.

Isi minimal per halaman:
- `MATERIAL.md`: materi final halaman.
- `FREEZE.json`: status approval dan spesifikasi final.
- `RENDERER-SNAPSHOT.py`: snapshot renderer saat halaman disetujui.

Baseline visual global mulai Clean V9:
- header: logo, teks kecil `QURBATA · JILID N`, nomor halaman;
- tanpa ornamen atau garis header;
- footer hanya teks Arab;
- kiri: `قُرْآنٌ · لُغَةٌ · أَدَبٌ`;
- kanan: `تَعَلَّمْ · اِعْمَلْ · عَلِّمْ`;
- font Arab: KFGQPC Uthman Taha;
- tanpa ornamen, blok warna, divider, atau medallion;
- materi utama tetap dominan.

Setelah suatu halaman disetujui, folder halaman tersebut menjadi sumber kebenaran permanen dan tidak boleh diubah tanpa review baru.
