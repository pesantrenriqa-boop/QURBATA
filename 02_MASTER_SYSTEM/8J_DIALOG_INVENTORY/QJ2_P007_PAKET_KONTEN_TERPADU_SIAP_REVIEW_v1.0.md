1. أَشِرْ إِلَى السِّينِ.
2. أَشِرْ إِلَى الشِّينِ.
3. كَمْ نُقْطَةً فَوْقَ الشِّينِ؟
4. هَلْ فَوْقَ السِّينِ نُقَطٌ؟
