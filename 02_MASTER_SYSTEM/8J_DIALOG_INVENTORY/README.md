# Inventaris Dialog QURBATA Jilid 1–8

Status: pengembangan pra-produksi. Sumber kompetensi Tartil tetap register resmi. Dialog pengantar kelas, dialog Tartil, dan dialog Tahfidz disusun sebagai lapisan pedagogis baru dan tidak diklaim sebagai kutipan ayat.

Tiga komponen wajib tiap halaman:
1. Pengantar: guru memberi salam, menyebut tujuan, memperagakan bacaan dalam bahasa Arab.
2. Tartil: guru bertanya sesuai kompetensi, santri menunjuk/membaca/menjelaskan, guru mengoreksi.
3. Tahfidz: guru membacakan ayat target, santri mengulang/menyetorkan; ayat harus sesuai baseline hafalan yang telah disahkan.

Status belum lengkap: penulisan respons dan pilihan ayat spesifik untuk 320 halaman masih membutuhkan pengumpulan sumber, verifikasi dan audit.
