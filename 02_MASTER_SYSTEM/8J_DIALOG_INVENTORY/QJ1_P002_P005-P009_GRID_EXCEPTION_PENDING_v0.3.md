## Catatan khusus P002
Dengan dua TARGET dan tiga REVIEW, sepuluh kelompok latihan yang masing-masing memuat dua TARGET hanya dapat menghasilkan enam kelompok tanpa pengulangan token internal (2 urutan TARGET × 3 REVIEW). Karena itu empat kelompok latihan berulang internal diperlukan untuk mempertahankan 40/66 TARGET dan 18 latihan unik pada konstruksi ini. Hal tersebut memerlukan pertimbangan pedagogis, bukan otomatis pengecualian gate duplikasi antarkelompok.
