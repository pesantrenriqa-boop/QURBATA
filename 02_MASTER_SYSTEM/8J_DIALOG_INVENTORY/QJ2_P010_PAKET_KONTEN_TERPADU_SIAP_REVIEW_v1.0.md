## 1 Tartil
Kartu: **ب / ت / ث / ج / ح / خ / س / ش / ص / ض / ط / ظ**. Fokus identifikasi bentuk, titik, bunyi dan sambungan sesuai prasyarat.

1. أَشِرْ إِلَى حَرْفٍ لَا نُقْطَةَ عَلَيْهِ.
2. أَشِرْ إِلَى حَرْفٍ تَحْتَهُ نُقْطَةٌ.
3. أَشِرْ إِلَى حَرْفٍ فَوْقَهُ ثَلَاثُ نُقَطٍ.
4. قَارِنْ بَيْنَ حَرْفَيْنِ مُتَشَابِهَيْنِ.
5. سَمِّ خَمْسَةَ حُرُوفٍ يُحَدِّدُهَا الْمُعَلِّمُ.

**Kunci spesifik:** 1 misalnya ح ص ط; 2 ب atau ج; 3 ث atau ش; 4 contoh ب/ت atau س/ش dengan titik; 5 lima kartu acak sesuai kunci guru. Perlu uji font KFGQPC Uthman Taha dan ahli fonetik.
