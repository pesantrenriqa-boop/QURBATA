## 1. Problem found
Existing RIQA-M01-TAHFIDZ-01 binds M01 to the entire J1 P001–P040 track, while RIQA-M02-TAHFIDZ-01 binds M02 specifically to P002 = An-Nas ayat 2 + review P001.
These two scopes cannot both serve as a clean four-Marhalah Book-1 allocation.

## 2. Resolution principle
To align Tahfidz with the approved Book-1 architecture and the already source-aligned Tartil M01–M04 split, use the same four natural 10-page phases:
- M01 = J1 P001–P010
- M02 = J1 P011–P020
- M03 = J1 P021–P030
- M04 = J1 P031–P040

This preserves the frozen corpus order and does not create, skip, or duplicate ayat. Existing M01/M02 frozen crosswalk files must NOT be overwritten silently; if this proposal is approved, issue superseding v2.0 crosswalks with explicit Decision-ID.
