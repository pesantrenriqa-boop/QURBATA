# RIQA MARHALAH — BOOK AUTHORING & EXPERIENCE STANDARD v1.0

**Status:** APPROVED BASELINE
**Date:** 8 September 2026
**Applies to:** RIQA Marhalah Books 1–5 / M01–M21
**Parent architecture:** RIQA-MARHALAH-01-21-MASTER-ARCHITECTURE-v1.0.md

## 1. Identity
The books must visibly express:
- **RIQA — Rumah Ilmu Al-Qur'an** as the parent ecosystem;
- **QURBATA** as the integrated Qur'an–Arabic–Tahfidz–Akhlak/NIDHOM learning method/ecosystem where applicable;
- **RIQA OS** as the digital competency, evidence, assessment, audio/recording, verification, and progress layer;
- **Marhalah M01–M21** as a clear SDM development journey.

The books are not ordinary subject textbooks. They are learning-and-competency journey books.

## 2. Mandatory Learning Flow
Each competency/unit should follow, as applicable:
**Tujuan Kompetensi → Pemantik/Aktivasi → Paparan Materi → Contoh → Praktik Terbimbing → Integrasi Domain → Pendalaman Pemahaman → Latihan/Praktik → Evaluasi Bervariasi → Refleksi/Akhlak → Evidence → Ketuntasan/Verifikasi → Jembatan ke kompetensi berikutnya.**

Written tests must not replace practical verification for performance competencies.

## 3. Evaluation Variety
Use forms appropriate to the competency, including:
- practical Qur'an reading;
- listening/selection;
- matching;
- completion;
- sequencing;
- Arabic response/use;
- simple analysis;
- tasmi';
- demonstration;
- ethical situation/case;
- reflection;
- bi'ah mission;
- quizzes;
- performance assessment and assessor verification.

## 4. Page Experience
Modern, clear, spacious, engaging, and non-monotonous. Maintain a consistent design system while varying page rhythm. Possible recurring learning components:
- Ingat;
- Coba;
- Praktikkan;
- Gunakan Bahasa Arab;
- Tahfidz;
- Akhlak RIQA;
- Tantangan;
- Checkpoint;
- Evaluasi;
- Evidence/Verifikasi.

Layout follows pedagogy, not decoration. Arabic/Uthmani text must receive adequate prominence and readability.

## 5. RIQA OS Integration
Printed and digital experiences form one ecosystem. Where useful, include:
- competency QR/link;
- competency/Marhalah ID;
- audio model;
- participant recording;
- interactive exercise;
- assessment;
- evidence submission;
- teacher/assessor verification;
- mastery/progress status.

Suggested action vocabulary: **SCAN · DENGARKAN · PRAKTIK · REKAM · VERIFIKASI**.

## 6. Visual Concept — “Perjalanan Kompetensi SDM RIQA”
The series must clearly communicate where the learner is on M01→M21.

Cover hierarchy:
1. RIQA — Rumah Ilmu Al-Qur'an
2. MARHALAH RIQA
3. Book number + Marhalah range + SDM stage
4. QURBATA ecosystem/method identity
5. RIQA OS digital integration cue

Use a modern path/ladder/node motif for M01→M21. The active range is emphasized while future stages remain visible as the journey ahead.

## 7. Five-Book Family
- Book 1 — M01–M04 · ANGGOTA
- Book 2 — M05–M08 · PRAKTISI
- Book 3 — M09–M12 · ASISTEN GURU
- Book 4 — M13–M16 · GURU
- Book 5 — M17–M21 · TRAINER → SUPERVISOR

The five covers/spines should form one coherent family; when displayed together, they may visually complete the M01→M21 journey.

## 8. Marhalah Opening Dashboard
Each Marhalah should open with a print-dashboard concept such as:
**MARHALAH 02 · POSISI SAYA 02/21 · ANGGOTA · BUKU 1**
with four-domain status/progress and the flow:
**Target → Belajar → Praktik → Evidence → Verifikasi → Lulus → Marhalah berikutnya.**

## 9. Visual Character
Balance:
**Qur'anic identity + academic clarity + modern educational technology + systematic competency journey.**

Use subtle Islamic geometry rather than decorative overload. Avoid a generic corporate-tech look and avoid making the book feel like a presentation deck.

## 10. Governance
This standard is approved for authoring the RIQA Marhalah series. Substantive changes require explicit approval and a new version.
