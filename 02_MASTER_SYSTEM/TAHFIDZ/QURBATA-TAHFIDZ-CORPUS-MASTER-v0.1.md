## 1. Purpose

This document operationalizes the frozen Hybrid Corpus Model into a corpus-selection and capacity framework for QURBATA Jilid 1–8.

The objective is not to force a preselected juz quota. The objective is to determine how much high-value Qur'anic memorization can be sustained across approximately 320 QURBATA learning units while preserving gradual load growth, tartil alignment, and retention quality.

## 3. Selection Scoring

Each non-sequential candidate is scored 1–5 on the frozen dimensions:

- F = Functional Value
- E = Educational Value
- M = Memorability
- T = Tartil Alignment
- C = Continuity into systematic tahfidz

Initial unweighted score:

`TOTAL = F + E + M + T + C` (maximum 25)

This score is for prioritization, not a theological ranking.

## 4. Anti-Duplication Rule

Selected corpus must not inflate the reported total when it is already contained inside the sequential juz reached by the learner.

Examples:
- Al-Mulk is part of Juz 29; if Juz 29 is completed, Al-Mulk is counted once.
- Al-Hashr is part of Juz 28; if Juz 28 is completed, Al-Hashr 22–24 is counted once.

Therefore the master corpus records both:

`pedagogical priority` and `unique Qur'anic coverage`.

## 5. Capacity Engine v0.1

The system uses approximately 320 page/meeting units as the current planning envelope.

Instead of equal load per page, use an increasing load curve.

### Draft load bands

| Jilid | Relative new-hifz load | Pedagogical role |
|---|---:|---|
| J1 | 1.0x | talqin-dominant entry |
| J2 | 1.4x | short stable units |
| J3 | 1.9x | reading-memory transition |
| J4 | 2.5x | medium units |
| J5 | 3.2x | independent growth |
| J6 | 4.0x | advanced volume |
| J7 | 4.8x | high sustainable volume |
| J8 | 5.5x | terminal QURBATA load |

These are relative weights only; they are **not frozen word counts**.

### Why this matters

A flat allocation wastes later learner capacity. A progressive curve allows J1 to protect beginners while J6–J8 carry substantially more Qur'anic text.

## 6. Retention Reserve

The corpus cannot consume 100% of instructional capacity as new memorization.

Initial simulation must test at least three retention-reserve scenarios:

- **R20:** 20% capacity protected for consolidation/evaluation;
- **R30:** 30% protected;
- **R40:** 40% protected.

The final corpus must survive at least the realistic school implementation scenario, not merely the most aggressive theoretical scenario.

---

## 7. Corpus Expansion Scenarios

### Scenario H3 — Foundation + 3 sequential juz

- CORE WAJIB;
- Juz 30;
- Juz 29;
- Juz 28;
- selected high-value passages only if capacity remains.

This is the first serious floor to test because it produces a materially stronger outcome than a Juz-30-only program.

### Scenario H4 — Foundation + 4 sequential juz

- CORE WAJIB;
- Juz 30–27;
- selected corpus inserted only when its value exceeds equivalent sequential capacity.

### Scenario H5 — Foundation + 5 sequential juz

- CORE WAJIB;
- Juz 30–26;
- selected corpus under strict capacity control.

### Scenario HX — Maximum sustainable hybrid

Continue sequentially beyond five juz until one of the following occurs:
- progression becomes too steep;
- retention reserve is violated;
- tartil alignment is violated;
- school-time implementation becomes unrealistic.

The highest scenario that passes all gates becomes the candidate terminal corpus.

---

## 8. Recommended Priority Logic

When capacity is scarce, use this order:

1. CORE WAJIB;
2. preserve sequential continuity;
3. insert selected corpus only when F/E value clearly justifies displacement;
4. protect retention reserve;
5. never increase juz count merely for marketing value.

This prevents the hybrid model from becoming a disconnected anthology.

---

## 9. Proposed Early-to-Late Shape

This is a structural hypothesis, not page allocation:

- **J1:** Al-Fatihah + very short CORE WAJIB + beginning sequential short-surah corpus.
- **J2:** accelerate through short-surah corpus.
- **J3:** continue Juz 30 with larger units; begin stronger reading-memory integration.
- **J4:** finish/secure Juz 30 and enter Juz 29 if measured capacity permits earlier.
- **J5:** sequential expansion, likely Juz 29/28 zone.
- **J6:** sequential expansion plus carefully chosen selected corpus.
- **J7:** high-volume sequential corpus.
- **J8:** maximum sustainable sequential corpus + terminal consolidation + bridge to 30-juz program.

No jilid-to-juz boundary is frozen here.
