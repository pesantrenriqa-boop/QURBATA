## 1. Purpose

First concrete page-level memorization map for QURBATA Jilid 1. It translates the frozen hybrid corpus architecture into 40 page/meeting targets.

This map is deliberately conservative at the beginning and increases load gradually. It must still be audited against the actual tartil competency/content on each QURBATA Jilid 1 page before freeze.

Al-Fatihah is treated as CORE WAJIB and Juz 30 begins from the end of the mushaf backward in a pedagogical sequence.

---

## 4. Why the Load Changes

P001–P013 intentionally use mostly one ayah per page because Jilid 1 begins at the earliest tartil stage and memorization is expected to be talqin-dominant.

The map then begins controlled compression:
- P014 combines two very short ayat;
- P032 combines a repetitive pair;
- P038–P040 progressively combine short ayat.

This tests the frozen principle that a QURBATA page is a pedagogical unit, not an automatic one-ayah container.

---

## 5. Critical Audit Before Freeze

This page map **must not yet be printed into the book** until the actual Jilid 1 tartil page content is cross-checked.

For every page P001–P040, audit:

1. Does the tahfidz target contain reading features far beyond the tartil skill introduced at that page?
2. If yes, is talqin sufficient, or should the target move later?
3. Is the word/phrase load proportionate to adjacent pages?
4. Does a combined target preserve a natural memorization boundary?
5. Does the target leave sufficient time for murojaah?
6. Are evaluation/non-standard pages in the production book actually available as new-hifz slots?

The sixth question is especially important: the current 40-slot model assumes all 40 pages can host a target. If Jilid 1 contains evaluation, akhlaq, Bahasa Arab, or other special pages where new tahfidz should not advance, the page map must be reflowed.

## 7. Relationship to Murojaah

This table contains **NEW HIFZ only**. It does not mean earlier targets disappear.

Murojaah will be generated by the separate QURBATA Tahfidz Retention & Validation System (QTRVS), using accumulated prior targets.

Example concept only:

`P020 NEW = Al-Fatihah 6`

while its murojaah pool may include Al-Fatihah 1–5 plus earlier completed surahs.

Do not mix the two fields in the corpus master.
