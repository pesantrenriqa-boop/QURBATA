# Font Arab Produksi

Keluaran produksi wajib memakai KFGQPC Uthman Taha Naskh. Simpan aset sebagai:

`KFGQPC-Uthman-Taha-Naskh.woff2`

Jangan mengganti dengan Amiri. Build dapat menampilkan fallback untuk pemeriksaan struktur, tetapi tidak boleh diberi status siap cetak sebelum font resmi tertanam dan lulus audit glyph, harakat, ligatur, serta embedding PDF.
