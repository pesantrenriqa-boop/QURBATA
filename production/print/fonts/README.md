# Amiri Quran

Font Arab produksi QURBATA ditetapkan sebagai **Amiri Quran**.

- proyek resmi: `https://github.com/aliftype/amiri`
- versi terkunci: `1.003`
- berkas: `AmiriQuran.ttf`
- lisensi: SIL Open Font License 1.1
- SHA-256: `5594121cfcd33d05ea4635b7908d15c0eced0c91aa06469a95354b3369ca2949`

Berkas biner font tidak disimpan langsung dalam repositori. Jalankan:

```bash
./production/print/fetch_amiri_quran.sh
```

Skrip mengambil font dari tag resmi, memeriksa checksum, dan menyimpan salinan lisensi.
