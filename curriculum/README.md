# Curriculum

## Hadis Akhlak Jilid 1–8

- `HCP-QUR-001-Hadith-and-Akhlak-Competency-Progression.md` mengendalikan tahapan, integrasi, murojaah, keunikan Full-Hadith-ID, dan gate aktivasi.
- `REG-HAD-001-Master-Hadis-Akhlak.md` adalah sumber tunggal hadis akhlak. Register sudah siap, tetapi belum ada Hadith-ID aktif sebelum takhrij dan validasi ahli.
- Kapasitas desain awal adalah satu slot kecil per halaman (maksimum teoretis 320 slot untuk 8 × 40 halaman); jumlah final tunduk pada keunikan, kesahihan, beban, dan keputusan ahli.

## Tahfidz Jilid 1

- `MAP-HAF-QJ1-001-Pemetaan-Tahfidz-dan-Murojaah-Jilid-1.md` memetakan kandidat Al-Fatihah ayat 1–7 secara bertahap pada P001–P040.
- Statusnya `CANDIDATE-CONTROLLED`; pemetaan tidak meratifikasi teks, model bacaan, atau Hafalan Object-ID.
