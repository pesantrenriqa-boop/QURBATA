# QURBATA Foundation Documents

The Foundation layer defines the non-negotiable identity, terminology, educational logic, outcomes, and research discipline of QURBATA.

## Controlled Document Register

| ID | Document | Purpose | Current status |
|---|---|---|---|
| F-001 | Constitution | Highest governing principles and authority | Existing source pending repository migration and later harmonization |
| F-002 | Lexicon | Controlled terminology and definitions | Existing source pending repository migration |
| F-003 | QURBATA DNA | Educational identity, design principles, and non-negotiable characteristics | Next document for full drafting |
| F-004 | Graduate Profile | Intended learner capabilities, character, and progression outcomes | Planned |
| F-005 | Research Protocol | Evidence, testing, validation, revision, and research governance | Planned |

## Authority Order

Where documents conflict, the project must stop implementation and perform a documented harmonization review. Lower-level curriculum or production material may not silently override a Foundation provision.

## Language Policy

Normative provisions are written in English. Indonesian explanatory notes may be added to improve institutional understanding and implementation, but they must not weaken or contradict the normative text.

## Current Work Sequence

2. Complete F-003.
3. Complete F-004.
4. Complete F-005.
5. Harmonize F-001 against the completed Foundation set.

## Document Control

Each Foundation document must state:

- document ID and title;
- version;
- status;
- owner or approving authority;
- effective date when approved;
- superseded version, if any;
- change summary.
