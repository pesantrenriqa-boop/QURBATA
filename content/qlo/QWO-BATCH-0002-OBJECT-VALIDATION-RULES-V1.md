# QWO Batch 0002 Object Validation Rules V1

## Tujuan
Menetapkan aturan sebelum kata Al-Qur'an menjadi QURBATA Word Object (QWO) aktif.

## Validasi Wajib

1. Validasi sumber
- Teks berasal dari ayat Al-Qur'an yang terverifikasi.
- Rujukan surah dan ayat wajib dicatat.

2. Validasi kompetensi
Setiap QWO harus memiliki:
- TargetCompetency
- RequiredCompetencies
- CumulativeCompetencies

3. Validasi pedagogis
Setiap kandidat dinilai:
- bentuk huruf
- harakat
- mad
- sukun
- tanwin
- tasydid
- panjang kata
- frekuensi kemunculan

4. Status objek
- ACTIVE: siap digunakan buku.
- REVIEW: perlu pemeriksaan.
- HOLD: belum sesuai tangga kompetensi.

## Prinsip utama
QURBATA tidak memilih kata karena mudah saja, tetapi karena kata tersebut merupakan contoh terbaik untuk mencapai kompetensi tertentu dengan tetap menjaga akumulasi kompetensi sebelumnya.
