# QCI Dependency Graph V1

## Purpose
Defines prerequisite relationships between competencies.

## Core sequence
Recognition Shapes -> Harakat -> Mad -> Tanwin -> Sukun -> Tasydid -> Word Fluency -> Phrase Fluency -> Ayah Fluency.

## Rules
- Every competency has a permanent ID.
- Every competency declares prerequisite competencies.
- Generators may not select learning objects requiring competencies that are not yet mastered.
