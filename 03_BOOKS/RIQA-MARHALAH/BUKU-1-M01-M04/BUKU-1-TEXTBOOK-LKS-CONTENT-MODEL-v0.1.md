## Standard Competency Chapter Pattern
1. **Tangga Saya** — posisi kompetensi saat ini + prerequisite yang sudah tuntas.
2. **Apa yang Akan Saya Kuasai** — observable mastery target.
3. **Pahami** — explanation, concept, distinctions, common errors as appropriate.
4. **Perhatikan Contoh** — canonical/whitelisted examples.
5. **Latih Bersama** — guided practice.
6. **Sekarang Saya Coba** — independent LKS.
7. **Gunakan pada Bentuk Baru** — transfer/generalization, not memorizing page examples.
8. **Pendalaman** — reasoning, matching, sequencing, analysis, language use, case, etc.
9. **Uji Kompetensi** — new/randomized items where appropriate.
10. **Evidence & Verifikasi** — practical/oral/written/observable according to domain.
11. **Status** — Tuntas / Belum Tuntas.
12. **Remedial or Next Step** — return to weak skill or unlock next node.

## M01.01 Revised Direction
M01.01 must not merely show بَ تَ ثَ examples. It must teach the competency:
- how to visually distinguish ب / ت / ث;
- how dot number/position differentiates forms;
- how to associate each symbol with the intended short sound in the current scope;
- how to listen, imitate, discriminate, read with support, then read independently;
- how to transfer to unseen/randomized allowed sequences;
- how to demonstrate mastery.

Arabic instructions such as اِسْتَمِعْ / كَرِّرْ / اِقْرَأْ are embedded as real classroom language. No explicit nahwu in M01.

Tahfidz uses only canonical allocation. Akhlak uses approved/controlled observable outcomes; no unapproved hadith is promoted to final content.
